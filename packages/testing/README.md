- **Invariants:** props and state values parse first (`schema.invalid`, nothing renders); `dispose` and transaction properties restore stores from `snapshot({ meta: true })`, so log `meta` survives. Sim ctx (`KEEL_SEED`, default 1337) unless `ctx` is given. Ids only: selector-shaped strings are E1701, absent ids E1705 with the 3 nearest. `find`/`a11y` never return nodes. `settle()` runs the same loop with no event (after a resource resolves); `fire` dispatches a real DOM event; resolves after two quiet microtask rounds (no timers; a quiet round first waits one `node:timers` `setImmediate` turn so a silent promise chain of any length drains), else `keel.unexpected`; a navigation still loading after 200000 macrotask turns rejects with `fire did not settle: <route> still loading after 200000 macrotask turns`. Root-Boundary catches (`onError`), and in `renderRoute` a render throw no `errorElement` caught (the router's root alert, `createRouterWith` `opts.onError`), fail with `keel.unexpected` and the thrown message; `a11y.json` mismatch (with `artifacts`) is E1702; Then the k.a11y render checks run, all of them, before the first failure throws: axe-core 4.14.0, synchronously, with the `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa` rules and `landmark-unique`, without `color-contrast` and, for `render`, without the document rules (`document-title`, `html-has-lang`, `landmark-one-main`, `region`, `bypass`), judging the container (`render`) or the document (`renderRoute`); a rule left `incomplete` did not run, and a requested rule that throws, or a run with no rule, fails with E1703; `label-content-name-mismatch` (canvas) and `link-in-text-block` (computed colors) are left out, since happy-dom cannot run them (E1703); contrast from atomic classes and `artifacts.tokens` per scheme and breakpoint, text without `fg` as `#000000`, `aria-hidden` text judged, `hidden` and disabled text exempt (E1804); a `data-k-pii` control without `autocomplete` (E1821). Within one test, a document whose markup, control values and focus equal one already judged reuses that axe verdict. Each check is recorded in the running vitest test's `meta.a11y`; outside a test nothing is kept. The harness adds the user-agent rule `[hidden] { display: none }` to the document, since happy-dom has none. Property failures throw E1704 with seed, run, shrunk case. Rungs (k.ledger): passing test `example`; seeded property >= 100 runs `probabilistic`; `exhaustive`, `proven` and `monitored` only from their own evidence kinds (`Evidence` `{ kind, passed, runs?, seed?, depth?, to? }`, `kind` one of `example`, `property`, `exhaustive`, `proven`, `monitored`). `ledgerDiff` reports lowered items (E1706, `see` k.ledger); `keel ledger` uses both. `renderRoute(id, { shell: true | { id } })` runs the page as in a native shell (k.return): navigations under the identity mount are mount requests through the ctx's `net` (sim routes answer them), `documents()` records each URL opened in the external browser as a GET (root-relative for one on `KEEL_ORIGIN`), and `returnLink(url)` delivers a return link on the shell's `id` and resolves when the page has settled (the router sorts it by path, k.links: a page navigates, a declared mount path sends one GET, any other mount path takes the pending opening, one link per opening, with the clock and storage of the ctx); the shell reports a launch with no link before the first render, and with `launch: 'later'` none until the handle's `launch(links)` (`null` for a failed read), which resolves when the links are delivered and the page has settled, a second report changing nothing; from a taken link until a person's act no chain records an opening (k.opening Link-started), and under `shell` a `fire` of `click`, `submit` or a `keydown` other than `Escape` is one, marked on the ctx before the event is dispatched, while any other `fire`, the handle's `navigate` and `settle`, and events the page's code dispatches are not; `shell: true` stands for the id `dev.keel.golden2`, and without `shell` `returnLink` and `launch` do nothing.
