# @keel/testing

**Spec:** k.testing, k.model, k.sim · **Status:** proposed · **verified:** (none)

## Contract

- **Public API:** `render(Component, { props, state?: [store, value][], ctx?, artifacts? }) -> { a11y(id?), state(store?), fire(id, event), settle(), find(id), dispose() }` · `renderRoute(id, { routes, params?, search?, ... }) -> Promise<same + route()>` · `resumeDocument(html, { routes, ctx?, artifacts? }) -> Promise<same>` (a server document's `<body>`, scripts dropped but `#k-state`, resumed through `resume` from `@keel/runtime-dom/ops` with each route's `component` by route id and every live store; a resume warning rejects with E1720 naming the first) · `properties(component | transaction, { runs = 100, seed? }) -> Promise<{ seed, runs }>` · `explore(transactions, { from?, payloads?, depth?, maxStates = 10000 }) -> Explored` (k.model; synchronous breadth-first over one store's transactions: each edge restores the state, runs `tx`, reads the output, and the store's snapshot with log `meta` is restored at the end; states are one when their sorted-key JSON is equal; payload domains are `payloads[name]` or every value of a finite payload schema (literals, enums, booleans, bounded integers, objects, unions and optionals of those, at most 256 values; object keys in declaration order, the last varying fastest); `Explored` is `{ states, edges, depth, complete, terminal }`; with none of `from`, `payloads`, `depth` it is the closed form: every transaction of the store, an empty log, a run that closes; E1708 an edge broke an invariant or threw, `data` `{ snapshot, transaction, payload }` with the shortest path as the snapshot's log (`at` counted from 1); E1709 `maxStates` (at most 1,000,000) reached; E1710 bad arguments; types `ExploreOptions`, `Explored`) · `simulate(scenario, { runs = 100, seed?, horizon = 600000, replay? }) -> Promise<{ seed, runs }>` (k.sim; each run draws a `SimRun` `{ seed, schedule }` with fast-check: net steps from `NetStep`, storage outcomes, offline windows inside the horizon, a plan per capability registered with `plan`; creates that sim ctx and awaits `scenario({ ctx, seed, schedule, run })`; `run()` settles, then while `ctx.clock.next()` is within `horizon` of the run's start advances to it and settles again; the live stores (`stores()`) are restored to their pre-`simulate` snapshots before each run and after the last; a failing run is shrunk and thrown as E1704 `simulate: <reason> (seed, run, shrunk)` with the shrunk `SimRun` as JSON on the next line; `replay` takes that JSON and runs it once; schema `SimRun`, types `Scenario`, `SimulateOptions`) · `ledger([{ item, evidence }])` · `ledgerDiff(before, after)`. A component is `(props, slots?, ctx?) => Node` with a static `Props`. · `testResults(files, errors, cwd) -> TestReport` (vitest's finished task tree as T0001 diagnostics at the first app frame, compact diff as `fix`, plus counts; shared by `keel test` and tooling's KeelReporter). `renderRoute` takes page ids only (an API route has no view; its id rejects). RFC 0070: `renderRoute(..., { caller? })`; the route handle has `navigate(href)`; `TestEvent` aliases k.ctx `FireEvent`.
- **Invariants:** props and state values parse first (`schema.invalid`, nothing renders); `dispose` and transaction properties restore stores from `snapshot({ meta: true })`, so log `meta` survives. Sim ctx (`KEEL_SEED`, default 1337) unless `ctx` is given. Ids only: selector-shaped strings are E1701, absent ids E1705 with the 3 nearest. `find`/`a11y` never return nodes. `settle()` runs the same loop with no event (after a resource resolves); `fire` dispatches a real DOM event; resolves after two quiet microtask rounds (no timers; a quiet round first waits one `node:timers` `setImmediate` turn so a silent promise chain of any length drains, RFC 0036), else `keel.unexpected`. Root-Boundary catches (`onError`) fail with `keel.unexpected`; `a11y.json` mismatch (with `artifacts`) is E1702; axe-like violations E1703 (rules: `image-alt`, `button-name`, `link-name`, `label`, `landmark-unique`; listed in `src/internal/axe.ts`). Property failures throw E1704 with seed, run, shrunk case. Rungs: passing test `example`; seeded property >= 100 runs `probabilistic`; `exhaustive`/`proven` only from their own evidence. `ledgerDiff` reports lowered items (E1706); `keel ledger` uses both.
- **Dependencies:** `@keel/schema`, `@keel/reactive`, `@keel/store`, `@keel/runtime-dom`, `@keel/router`, `@keel/compiler` (types), `@keel/ctx`, `fast-check`.
- **Rungs:** conformance; properties (a11y names, ledger monotonicity), seed 1337.
