# @keel/testing

**Spec:** k.testing, k.model, k.sim · **Status:** conformance-covered · **verified:** (none)

## Contract

- **Public API:** `render(Component, { props, state?: [store, value][], ctx?, artifacts? }) -> { a11y(id?), state(store?), fire(id, event), settle(), find(id), focusOrder(), dispose() }` (`artifacts` `{ "a11y.json"?, tokens? }`; `focusOrder()` the ids of focusable elements in sequential order, without disabled, `hidden`, `inert` or `display: none` ones)` · `renderRoute(id, { routes, params?, search?, ... }) -> Promise<same + route()>` (a document: `<title>` and `<html lang>` from the router, the route id as the title when the document has none, the chain the `main` landmark unless it renders one) · `resumeDocument(html, { routes, ctx?, artifacts? }) -> Promise<same>` (a server document's `<body>`, scripts dropped but `#k-state`, resumed through `resume` from `@keel/runtime-dom/ops` with each route's `component` by route id and every live store; a resume warning rejects with E1720 naming the first) · `properties(component | transaction, { runs = 100, seed? }) -> Promise<{ seed, runs }>` · `explore(transactions, { from?, payloads?, depth?, maxStates = 10000 }) -> Explored` (k.model; synchronous breadth-first over one store's transactions: each edge restores the state, runs `tx`, reads the output, and the store's snapshot with log `meta` is restored at the end; states are one when their sorted-key JSON is equal; payload domains are `payloads[name]` or every value of a finite payload schema (literals, enums, booleans, bounded integers, objects, unions and optionals of those, at most 256 values; object keys in declaration order, the last varying fastest); `Explored` is `{ states, edges, depth, complete, terminal }`; with none of `from`, `payloads`, `depth` it is the closed form: every transaction of the store, an empty log, a run that closes; E1708 an edge broke an invariant or threw, `data` `{ snapshot, transaction, payload }` with the shortest path as the snapshot's log (`at` counted from 1); E1709 `maxStates` (at most 1,000,000) reached; E1710 bad arguments; types `ExploreOptions`, `Explored`) · `simulate(scenario, { runs = 100, seed?, horizon = 600000, replay? }) -> Promise<{ seed, runs }>` (k.sim; each run draws a `SimRun` `{ seed, schedule }` with fast-check: net steps from `NetStep`, storage outcomes, offline windows inside the horizon, a plan per capability registered with `plan`; creates that sim ctx and awaits `scenario({ ctx, seed, schedule, run })`; `run()` settles, then while `ctx.clock.next()` is within `horizon` of the run's start advances to it and settles again; the live stores (`stores()`) are restored to their pre-`simulate` snapshots before each run and after the last; a failing run is shrunk and thrown as E1704 `simulate: <reason> (seed, run, shrunk)` with the shrunk `SimRun` as JSON on the next line; `replay` takes that JSON and runs it once; schema `SimRun`, types `Scenario`, `SimulateOptions`) · `ledger([{ item, evidence }])` · `ledgerDiff(before, after)`. A component is `(props, slots?, ctx?) => Node` with a static `Props`. · `testResults(files, errors, cwd) -> TestReport` (vitest's finished task tree as T0001 diagnostics at the first app frame, compact diff as `fix`, plus counts; shared by `keel test` and tooling's KeelReporter). `renderRoute` takes page ids only (an API route has no view; its id rejects). `renderRoute(..., { caller? })`; the route handle has `navigate(href)`; loaders and actions naming `stores` run their factories over `ctx.storage` through the server's runner (`serverState` from `@keel/store/internal`, the router from `createRouterWith`), each navigation or submit one request: seed a store by writing its `keel.store.<id>` snapshot JSON to `ctx.storage` before the first render, then render and submit; an action's `ok` saves and reports `save`, a stale read is `keel.conflict` in the Form, `err` or a throw saves nothing; `state` and `state()` hold no factory store, and `dispose` leaves storage as the test made it; `TestEvent` aliases k.ctx `FireEvent`. `@keel/testing/a11y` (Node): types `A11yRun` `{ route, component, rules, violations: { rule, element }[], file, test, passed }` and `A11yCase` `{ file, test, passed, meta }`; `writeA11yReport(root, cases) -> A11yRun[]` writes `<root>/reports/a11y.json` from each test's `meta.a11y`; `criteriaOf(rule)` the WCAG 2.2 A/AA criteria of an axe-core rule (its `wcag` tags) or of E1702, E1802, E1804, E1820, E1821; `a11yRules()` every rule a `renderRoute` check can run; `WCAG_CRITERIA` the 55 A and AA criteria.
- **Invariants:** props and state values parse first (`schema.invalid`, nothing renders); `dispose` and transaction properties restore stores from `snapshot({ meta: true })`, so log `meta` survives. Sim ctx (`KEEL_SEED`, default 1337) unless `ctx` is given. Ids only: selector-shaped strings are E1701, absent ids E1705 with the 3 nearest. `find`/`a11y` never return nodes. `settle()` runs the same loop with no event (after a resource resolves); `fire` dispatches a real DOM event; resolves after two quiet microtask rounds (no timers; a quiet round first waits one `node:timers` `setImmediate` turn so a silent promise chain of any length drains, RFC 0036), else `keel.unexpected`. Root-Boundary catches (`onError`) fail with `keel.unexpected`; `a11y.json` mismatch (with `artifacts`) is E1702; Then the k.a11y render checks run, all of them, before the first failure throws: axe-core 4.14.0, synchronously, with the `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa` rules and `landmark-unique`, without `color-contrast` and, for `render`, without the document rules (`document-title`, `html-has-lang`, `landmark-one-main`, `region`, `bypass`), judging the container (`render`) or the document (`renderRoute`); a rule left `incomplete` did not run, and a requested rule that throws, or a run with no rule, fails with E1703; `label-content-name-mismatch` (canvas) and `link-in-text-block` (computed colors) are left out, since happy-dom cannot run them (E1703); contrast from atomic classes and `artifacts.tokens` per scheme and breakpoint, text without `fg` as `#000000`, `aria-hidden` text judged, `hidden` and disabled text exempt (E1804); a `data-k-pii` control without `autocomplete` (E1821). Within one test, a document whose markup, control values and focus equal one already judged reuses that axe verdict. Each check is recorded in the running vitest test's `meta.a11y`; outside a test nothing is kept. The harness adds the user-agent rule `[hidden] { display: none }` to the document, since happy-dom has none. Property failures throw E1704 with seed, run, shrunk case. Rungs (k.ledger): passing test `example`; seeded property >= 100 runs `probabilistic`; `exhaustive`, `proven` and `monitored` only from their own evidence kinds (`Evidence` `{ kind, passed, runs?, seed?, depth?, to? }`, `kind` one of `example`, `property`, `exhaustive`, `proven`, `monitored`). `ledgerDiff` reports lowered items (E1706, `see` k.ledger); `keel ledger` uses both.
- **Dependencies:** `@keel/schema`, `@keel/reactive`, `@keel/store`, `@keel/runtime-dom`, `@keel/router`, `@keel/compiler` (types), `@keel/ctx`, `@keel/ui`, `fast-check`, `axe-core` (test-time; never in an app bundle).
- **Rungs:** conformance; properties (a11y names, ledger monotonicity), seed 1337.
