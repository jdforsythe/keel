# @keel/services

**Spec:** k.services · **Status:** conformance-covered · **verified:** (none)

## Contract

- **Public API:** `endpoints({ name: { method, path, params?, query?, body?, output, errors?: { [status]: schema }, timeout?, events? } })` returns the frozen declarations. `service({ contract, timeout? })` returns a client with one method per API entry of a module's contract (`@keel/router/contract`, the only router code this package imports), named by the entry's id after the module (`kitchen.box` is `.box`), and `service({ base, schema, timeout? })` one with a method per endpoint of another service: `(input: { params?, query?, body?, signal?, bearer?, user? }, ctx) => Promise<Result<Out, ApiError>>`, or for an `events: true` GET an `AsyncIterable<Result<Out, ApiError>>`. A `contract` call's `user` (k.user) is sent as `x-keel-user`, signed by the `createApp` that bound the ctx for the body as sent and the deployable that serves the module; on a ctx no `createApp` bound, or for a `user` that is not a string (`type`) or over 256 characters (`max`), it is `api.input` at `user` and nothing is sent. Types: `ApiError`, `Client`, `ContractClient`, `Endpoint`, `EndpointMap`, `Method`, `ServiceOptions`.
- **Invariants:** a call never throws or rejects. Requests go through `ctx.net.fetch`. `ApiError` by `code`: `api.timeout { ms }` (default 10,000 ms, endpoint overrides service; measured by `ctx.clock.after`; aborts the request signal), `api.network {}` (fetch or body read rejected, or the platform refused the Request), `api.status { status, body }` (`body` decoded by `errors[status]`, else or on failure `null`), `api.decode { issues }` (2xx body fails `output`, or a `module` answer is not the route's `ok` `Result`), `api.input { issues }` (call input fails its schema: paths prefixed `params`/`query`/`body`, or a `bearer` outside k.api's Bearer form at `bearer`; nothing sent). Path params are `encodeURIComponent`ed; query is the inverse of `decodeStrings` (dotted keys, repeated keys, null absent); body is JSON; every request sends `accept: application/json`, `x-keel: 1` only to a Keel origin (every `contract` target; for `base`, the document's origin, a `keel-peer` origin or a URL peer of the `createApp` that bound the ctx; a third party gets no Keel header and no cookie), and with `bearer` (a `Secret<string>`, revealed only to build the header) `authorization: Bearer <token>`, an `events: true` GET included. An empty 2xx body is `null`. `service` throws at construction on a relative `base`, a `module` that is not an id, or a timeout that is not a finite ms > 0. `signal` aborts the request.
- **Module calls** (k.topology Calls and peers): `module` resolves per call. On a ctx a `createApp` or a `client` entry bound (the `globalThis` key `Symbol.for("keel.modules")`, written by `@keel/server` and the generated entry, k.hosting Peers), the app serving the module in this process answers through its `fetch` with no `ctx.net.fetch`, and an origin by URL through `ctx.net.fetch` to that URL; otherwise a browser calls `location.origin`, anything else `http://<module>.keel.invalid`. In a browser a call to an origin other than `location.origin` is sent with `credentials: "include"`. Every path encodes and sends the same headers. A `module` call reads the k.server answer's `Result` (a GET's `results[id]`, the matched route's own level; an action's body): on a 2xx its `ok` value is decoded with `output`, on a non-2xx its `err`'s KeelError `{ code, message, data }` with `errors[status]`. A `base` call decodes the body itself. No redirect is followed: a 3xx is `api.status` (in a browser `status` 0, an opaque redirect).
- **Events** (k.services, a k.server live loader): one request with `accept: text/event-stream`; the timeout applies until the response starts. A non-2xx answer is one `api.status` and the end. Each event's `data` is a `Result` JSON: `ok` decoded with `output` (`api.decode` then the end), `err` as `api.status` 200 with the error as `body`, then the end. One event is at most `maxBytes` (default 1 MiB): its line block, every line, comment and line end counted through the blank line that ends it; once a block passes `maxBytes` the body is cancelled and the iteration yields one `api.decode` (issues `[{ path: [], rule: 'max' }]`) and ends. The body is read in steps linear in its bytes. A body error is `api.network`; an aborted `signal` ends it with no further result; it never reconnects or resumes, and leaving the loop aborts the request.
- **OpenAPI**: `openapi(doc, { name })` from `@keel/services/openapi` (build time; `name` is lowerCamel, `/^[a-z][A-Za-z0-9]*$/`, else a `RangeError`) returns `Result<{ schema, service }, SchemaError>`, the sources of `<Name>Api.schema.ts` (`<Name>Api = endpoints(...)`, filename equals export, one endpoint per `operationId`, refs inlined, unsupported schemas `s.json()`) and `api.server.ts` (imports `./<Name>Api.schema.ts`; a literal `base` is server-only, E1571); a doc outside the subset is `schema.invalid` with paths into the doc. Types: `OpenApiFiles`, `OpenApiOptions`.
- **Dependencies:** `@keel/schema`, `@keel/ctx`.
- **Rungs:** conformance; properties (seed 1337): query/param/body round trips, never-throws, openapi one-endpoint-per-operation and biome-stable output; mutation 88.0%.

## Extension points

None. Retries, caching, getting and refreshing tokens, and interceptors are stdlib. E1651-E1653 are `@keel/check` rules, asserted in this suite through `check()`.

## Unsafe

count: 2
- `unsafe/fetcherOf.ts`: a module's object entry in the bound module table typed as the in-process app it is.
- `unsafe/signerOf.ts`: the bound module table's `keel.user` function typed as the `x-keel-user` signer.
