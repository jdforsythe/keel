# @keel/ui

**Spec:** k.ui · **Status:** conformance-covered · **verified:** (none)

## Contract

- **Public API:** `defineTokens` (throws `E1807`), `TokenSchema`, `contrastTable(tokens)` -> `ContrastRow[]` (`{ scheme, fg, bg, ratio }` for every ordered pair of distinct color tokens per scheme, ratio to two decimals; a value that is not `#rgb`/`#rrggbb` is left out). Base elements `Box Text Heading Button Link Image Frame Input TextArea Select Checkbox`: `(props) => Node`, `children` prop (plain, or the `Children` thunk the compiler delivers). `@keel/ui/css`: `compileStyles({ tokens, usages })` -> `{ classes, css }`, `contrast(fgHex, bgHex)`. Types: `Tokens`, `TokenName`, `StyleProps`, `Child`, `StandardSlots`, ... (`Href` comes from `@keel/router`).
- **Invariants:** style values are `TokenName` strings (existence is `check`'s E1801) or a signal/computed; responsive by breakpoint (`base` + names); state styles under `states={{ hover, focusVisible, active, disabled }}`, and on `Part` also `selected` (`[aria-selected="true"]`), `checked` (`[aria-checked="true"]`, `:checked`), `expanded` (`[aria-expanded="true"]`), `highlighted` (`[data-k-highlighted]`), written before the interaction states in the CSS. One class per (prop, token, breakpoint, state): `k-[bp-][state-]prop-token` (`_hash` suffix if not alphanumeric). `compileStyles` is pure: `:root` vars, dark/reduced-motion overrides, base rules, `min-width` blocks, state rules; `E1801` on unknown token. Dynamic values bind one `attr(class)`; never a `style` attribute. Controls render `<label for>` + control; id = `field.id`, else `id`, else `k-<kind>-<label-slug>` (`-2`, `-3`... if taken in the document or this render). `field` (k.forms) binds the control; its error renders under `field.errorId`. A reactive `value`/`checked` binds the property and writes its first value as the markup default (`value` attribute, textarea text, `selected`, `checked`; none on a `password` Input), so server HTML shows it and later writes, the user's included, change only the property. `disabled` on `Button` and controls. `Input`, `TextArea`, `Select` take `autocomplete: Autofill` (the WCAG 2.2 input purposes plus `off`), written as the attribute. `Button` is named by its children (no `label`); style props are the only styling (no `class`, no `styles()`). `Link to: Href`. Event props, closed: `Button onClick`, `Checkbox onChange(checked)`, `Input`/`TextArea onInput(value)`, `Select onChange(value)`; none elsewhere. `Image decorative` -> `alt=""` `role="presentation"`. `Frame` renders an `<iframe>`: `src` that is not an absolute http(s) URL becomes `about:blank`; `title` is required (E1802, blank too); optional `allow` from `autoplay`, `encrypted-media`, `fullscreen`, `picture-in-picture` (joined with `; `); `loading="lazy"`, `referrerpolicy="strict-origin"` and `sandbox="allow-scripts allow-same-origin allow-popups allow-presentation"` are fixed; it takes `id`, `lang` and `style` props. Its origin is declared under `frame` in `topology.ts`. URLs pass `safeUrl`. A base element with an event prop, a `field`, or a signal or computed (value, checked, disabled, style, child) carries `data-k`, so the server makes its route level an island; thunk children resume in place (a claimed element keeps the server regions and op anchors among its children, which an `If` or `For` child claims), an eager `Node` child is E1253, and `check` reports an eager element child as E1808.
- **`@keel/ui/aria`** (kernel and stdlib only; app code is E1822): `Part(props: PartProps) => Node`, the one element stdlib widgets are built from. `role` fixes the tag and the ARIA props (`PartProps` is a union discriminated by `role`; `PartRole`); `role` is written only where it differs from the tag's implicit role. Props: `id` (required), `lang`, `hidden`, `tabIndex` (`0` or `-1`), style props with `states` also taking `selected`, `checked`, `expanded`, `highlighted` (`PartStyle`, `PartState`), `children` thunk, `focus` (focuses on a false-to-true change, never at the first render or resume), `onKey(key: KeyInput) => boolean` (`{ key, shift, alt, mod }`; true prevents the default and stops propagation), `onClick`, `onFocus`, `onBlur`, `onInput(value)` on `combobox`, `onDismiss` and `returnFocus` (an element id) on `dialog` and `alertdialog`. ARIA values take a value, a signal or a computed. `option` and `menuitem*` prevent `mousedown`; `activeDescendant` marks the named element `data-k-highlighted` and scrolls it into view on a change; `dialog` and `alertdialog` call `showModal()` when `open` turns true, focus the first control (else the dialog, `tabindex=-1`), and on close, or removal while open, focus the element `returnFocus` names, else the one focused at open, else `main`; `cancel` is prevented and calls `onDismiss`.
- **Dependencies:** `@keel/schema`, `@keel/reactive`, `@keel/runtime-dom`, `@keel/router`, `@keel/forms` (types).
- **Rungs:** conformance, properties.

## Extension points

None. Token names are not typed per app (principle 2); `check` validates them against `tokens.ts`.
