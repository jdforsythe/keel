# @keel/schema

**Spec:** k.schema, k.formats, k.errors (Result, KeelError, attempt), k.privacy · **Status:** conformance-covered · **verified:** (none)

## Contract

- **Public API:** `s.string({min,max}) | number({min,max}) | int({min,max}) | boolean() | literal(v) | enum([..]) | id(brand) | object({..}, { closed? }) | array(T) | union(key, [..]) | union([A, B, ..]) | record(T) | secret(T) | error(code, D) | result(T, E)`; `reveal(secret)`; modifiers `.optional()` (key may be absent), `.nullable()` (value may be null). `.pii(class)` marks a node and everything under it as personal data (`PiiClass`: `name`, `contact`, `location`, `identifier`, `financial`, `special`, `network`, `content`); an object keeps `decodeStrings`. `piiPaths(schema)` -> `{ path, class }[]`, one per marked leaf in declaration order, dotted, `*` for an array item or record value, class of the nearest mark, and `<object>.*` (`*` at the root) after the fields of a marked open object for the keys it does not declare; a lookup of one path reads it through declared fields, so a declared path, leaf or not, takes its nearest mark's class; `piiValues(schema, value)` -> the distinct non-empty strings and numbers (as `String()`) under marked paths, with a marked record's keys and a marked open object's undeclared keys and values. Each schema: `parse` -> `Result<T, SchemaError>` (no `decode`), `encode` -> `JsonValue`, `doc()`, `node`. Generators: `gen(schema)` from `@keel/schema/gen`. `s.error(..).make(data, message?)`. `s.infer`, `s.register`, `s.registry()`. `ok`, `err`, `attempt(fn)`. `pathToString(path)` (`users.0.name`). `s.object(..)` schemas also have `decodeStrings(FormData | URLSearchParams | Record<string, string | string[]>)`. Types `Result`, `KeelError`, `SchemaError`, `Schema`, `Infer`, `JsonValue`, `Secret`, `PiiClass`, `PiiPath`.
- **Invariants:** parse/attempt never throw. `SchemaError` is the plain KeelError `schema.invalid` listing every issue `{ path, rule }`, `rule` from a closed set; no E-codes at runtime. Valid input is returned by reference (not copied; mutating it afterwards mutates the parsed value), except that a schema containing `s.secret` copies the containers above each secret it wraps. A secret's value is frozen deep once the whole value passes its check: the value and each object and array under it, in place (a failed parse freezes nothing, and a value the check or the freeze cannot walk, such as a typed array, a throwing getter or a revoked Proxy, is an err), so the caller's own object is frozen where the inner schema keeps it (`s.json()`), and writing into a revealed value throws a `TypeError` in strict mode; copy it first (`structuredClone`). `Secret<T>` prints, serializes and inspects only as `"[secret]"`; `encode` gives the marker; parsing the marker fails with rule `secret-missing`; `reveal` is the only read path. `parse` rejects an object with an own `__proto__`, `constructor` or `prototype` key (rule `type` at its path). `s.string({min,max})`, `s.number({min,max})` and `s.int({min,max})` throw at construction when `min > max`; number/int bounds are inclusive (rules `min`/`max`, after `type`/`finite`/`int`). `s.json()` accepts exactly JSON-representable values (finite numbers, plain objects/arrays, no cycles or prototype keys; else rule `type`), encode/parse are identity, `decodeStrings` parses the text as JSON. `parse` keeps undeclared keys (a `{ closed: true }` object reports each with rule `unknown-key` instead), but fails with rule `type` at a `Secret` anywhere under one; `union([..])` accepts with the first accepting member, else reports the last member's issues; `encode` keeps declared keys only (unknown keys are dropped) (absent stays absent, null stays null) and throws an `Error` on invalid input. `parse` is also the JSON inverse of `encode` (`parse(encode(v))` equals `v`, except secrets); `decodeStrings` coerces form/URL text: numbers from numeric strings, booleans from `true|on|1` / `false|off|0` (absent boolean is false), empty string for an optional key is absent, arrays from repeated keys or `key[]`, nested objects by `a.b` keys, records from `prefix.key`, unions by discriminant; text that cannot be coerced is left as is and reported by validation (`type`, `literal`, ...); every `gen(schema)` sample parses. `attempt` maps throws/rejections to `keel.unexpected`. A mark changes no derivation (`parse`, `encode`, `decodeStrings`, `gen`): the node gains `pii: class` and `doc()` appends ` pii(<class>)`.
- **Internal:** `@keel/schema/internal` exports `blankPattern`, the JSON Schema `pattern` of a `string` with `min` >= 1 (a negated class of `\uXXXX` ranges: the blank set below U+10000 but `M` and `Cs`), for `@keel/cli` and `@keel/router`, `secretPathOf(node)` (the object-key path of the first `secret` node, or null) for `@keel/store`, `onSecret(listener)`, one listener slot `Secret.of` calls with each new `Secret` and `reveal` with each `Secret` it opens, before it opens it (the returned function clears it), and `secretWalk(value)`, each non-empty string, number (as `String()`) and data key inside each `Secret` under `value`, not app-facing. A `Secret` holds the node it was sealed under, and `secretWalk` reads its value beside that node: a record's keys, a `json` value's keys and an object's undeclared keys (open or closed) are data and are given, a declared field name is not; a value no union variant or member fits, or whose shape is not its node's, is read whole (every string, number and own key at any depth). A boolean and the empty string are never given; one read visits at most 1,000,000 values. It returns `{ values, cut }`: `values` as above, `cut` true when values were left unread past the 1,000,000, for `@keel/server`, which then treats the request's set as past its cap.
- **Dependencies:** `fast-check` is a peer dependency, imported only by `@keel/schema/gen` (`src/gen.ts`); the main entry is 5.1 kB gz and never loads it. Hand-written validator.
- **Rungs:** probabilistic: conformance and `test/` properties, seed 1337. Inference: `expectTypeOf` under `tsc`.

## Extension points

`s.register(name, schema)`: same schema again is a no-op; a different schema under a taken name throws. `s.registry()` returns a snapshot `Map`.
