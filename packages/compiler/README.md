# @keel/compiler

**Spec:** k.compiler + k.component (+ k.module `module()`) · **Status:** implemented · **verified:** (none)

## Contract

- **Public API:** `compile(files, { mode?, topology?, routes? })` -> `{ outputs, artifacts, hashes, diagnostics }`. `topology` (parsed `topology.ts`) exempts files of `client` deployables from E1004; `routes` is a precomputed `routes.json` (default `{}`). `module(def)` / `ModuleSchema` (k.module manifest: `ModuleSchema` includes the lowerCamel `id` rule; `module` validates, returns the frozen def unchanged, throws `code: 'keel.module'`). `@keel/compiler/tsconfig.strict.json`: the strict app profile (no `jsxImportSource`; JSX is lowered by the plugin). `@keel/compiler/testing` (dev-only; optional peer `esbuild`, DOM env): `evaluate(code)`.
- **Vite plugin** (`@keel/compiler/vite`, no options): compiles each changed module under the root (linked workspace packages are skipped), merges artifacts, writes `.keel/{a11y,deps,ids,routes,styles}.json` as read-only `{ data, hash }` atomically and only on change. Reads `topology.ts` statically at `configResolved`. At `buildStart` it compiles every app source (no tests) for style usages and evaluates `tokens.ts` and the deployable's `modules/<id>/routes.ts` once at build time (esbuild bundle from the app root, run in Node): `compileStyles` from `@keel/ui/css` -> the `virtual:keel.css` module (`/__keel.css`); `routesArtifact` from `@keel/router` -> `routes.json`. For a `client` deployable (`KEEL_DEPLOYABLE` or the first by name) it serves the generated entry **`/@keel/entry.ts`** (index.html: `<div id="app"></div><script type="module" src="/@keel/entry.ts"></script>`): imports `virtual:keel.css`, `createCtx({ mode: 'real' })`, `createRouter(<merged manifests>, { ctx, history: browserHistory() })`, `mount(router.App, #app, { ctx })`, and in dev builds (`import.meta.env.DEV`) posts `{ graph: inspect(), stores }` to `/__keel/inspect` after mount and then at most once a second on change. Dev and preview servers serve `GET /__keel/inspect` (k.cli Inspect): `.keel/` ids, a11y, routes plus the last posted live half (`live: false` before one); POST JSON only; GET and POST answer only a loopback or listed `Host` with an absent, own, or listed `Origin` (extra origins from comma-separated `KEEL_INSPECT_ORIGINS`, `:*` any port; listed ones get CORS; others 403 `keel.denied`, RFC 0022). Build-time only: the plugin needs `esbuild` and the app must depend on `@keel/ui`, `@keel/router`, `@keel/ctx`, `@keel/runtime-dom`.
- **Output:** JSX lowers to `@keel/runtime-dom/ops`: one hoisted `template(html)` per element root, cloned once per render; each dynamic expression is exactly one `text`/`attr`/`prop`/`on` binding; `<Foo a={x}>kids</Foo>` is `Foo({ get a() { return x }, children: () => kids }, undefined, ctx)` where `ctx` is the enclosing component's third parameter (added when absent); `{props.children()}` / `{slots.x()}` are inserted as nodes. `If`/`For`/`Match`/`Boundary` lower to `cond`/`list`/`match`/`boundary`. Static style props on `@keel/ui` base elements become one `class` with ui's atomic names; dynamic ones stay props. A file exporting `uses` runs its default-export component in its own scope that declares them (`t.store.uses([t])`). Top-level `store`/`signal`/`computed`/`resource` are created in a module root scope; exported stores under `modules/<id>/` get `{ id: '<id>.<export>' }`. TypeScript outside JSX is otherwise kept byte for byte.
- **Artifacts:** `styles.json` `{ usages: [{ props: { <prop>: <token> }, breakpoint?, state? }] }` (one per literal token, dynamic `?:`/`&&` leaves included, deduplicated, sorted); `routes.json` per k.router; `ids.json`/`a11y.json` include `@keel/ui` base elements with a literal `id` (by the DOM tag they render).
- **Ids:** literal `id` kept, else `<path>.<ordinal>` over the file's DOM elements (`src.orders.OrderList.0`); written into the template.
- **Invariants:** `compile` is pure and deterministic (sorted keys, FNV-1a hash per artifact, no clock, no fs); static text and attributes are HTML-escaped at compile time; literal `javascript:`/`data:` URLs become `about:blank`.
- **Diagnostics:** E1001 E1002 E1003 E1004 (k.compiler), E1401 (unified-patch fix) E1402 E1403 E1404 (k.component; base-element ids count), E1501 for string paths in `href`/`src`/`action`/`formaction`, `Link to`, `Image src` (absolute URLs and `#x` allowed; E1003 wins), E1000 syntax error (pending spec line). Unknown tokens in `keel.css` are left out and warned (E1801 is `check`'s).
- **Dependencies:** oxc-parser, magic-string; runtime-dom, reactive, schema, store; esbuild (optional peer: `evaluate` and the Vite plugin). The generated code imports `@keel/reactive` and `@keel/runtime-dom/ops`; the generated entry and the build-time evaluator import router/ui/ctx (and the entry reactive/store) from the app.
- **Rungs:** conformance (example + probabilistic), property tests (determinism, ids, XSS, class-name parity with ui).
