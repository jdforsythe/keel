# @keel/runtime-dom

**Spec:** k.runtime · **Status:** conformance-covered · **verified:** (none)

## Contract

- **Public API:** `.`: `mount(Component, el, { ctx, onError?, mode? }) -> dispose` · intrinsics `If`, `For`, `Match`, `Case`, `Boundary`. Types: `Component<P>` `(props, ctx) => Node`, and `Island` the same; every caller passes `ctx`, and a component that reaches no effect may leave it out. A named slot is a prop. `./ops` (compiler and generated entry only): `template` (where `globalThis.trustedTypes` exists its HTML passes through the policy `keel`, created once per realm and shared by every runtime copy; a policy the browser refuses throws an Error naming it), `clone`, `text`, `attr`, `prop`, `on`, `cond`, `list`, `match`, `boundary`, `host(el, { id, input, value, live, code, events, onEvent })` (k.host-element, k.host-code; `@keel/ui`'s `Host` calls it on its `div`: nothing on the server; resume never claims `el`'s children; on a harness ctx `code` never runs and the element is registered for the harness's `find` and `fire`; otherwise `code()` resolves, `mount` runs in the next animation frame with the current value, a change of a `live` value requests a frame when none is pending and the frame calls `update(value, prev)` unless the latest value `Object.is` the one last given; under `mode: 'dev'` and in a harness `input` parses each value first, a failure being `schema.invalid` to the nearest Boundary with no `mount` or `update`; each `emit` is parsed by `events`, reported as a `fire` `{ type: 'emit', detail }` (`detail` encoded by `events`) and given to `onEvent` as a handler; scope disposal cancels a pending frame, calls `dispose` once, its throw reported to the ctx as an `error` and dropped, then aborts the code's `signal`; any other throw goes to the Boundary with `data.at` the id; types `HostDef`, `HostStart`), `frag(build)` (multi-item content: `build` appends the items; outside a claim it returns the fragment, while resuming nothing moves and the empty fragment returned stands for its items' nodes in place), `parts(node)` (those nodes, for a consumer such as `@keel/ui`'s children; undefined for any other node), `resume(root, components, { ctx, stores?, mode? }) -> { warnings }`; root components get `ctx` second; `reveal(el)` (an element built `hidden`, such as `@keel/ui`'s `SchemeSelect`: the server keeps the attribute, and the `mount` or `resume` building it in the browser removes it when it ends). `./internal` (`@keel/server`, `@keel/router` and `@keel/testing` only): `harnessed()` (the realm's set of harness ctxs, shared by every runtime copy) and `hosts` (the host elements rendered on them, each `{ value(), emit(detail) }`), `serverMode` (`{ on }`: while on, every structural op and every slot other than a component slot `<!--+-->` writes its content in a region `<!--[-->` … `<!--]-->` before its anchor; k.resume) the `E1255` message, `servedForm` (`{ current }`: the rejected post the render shows, `{ href, method, values, errors }`; the server sets it around a 422 re-render, `resume` from `#k-state`'s `form` around its islands; `@keel/router`'s `<Form>` reads it), and `made` (`{ on, seq, from, eager }`: while on, each element `clone` or `element` makes is stamped, and an `element` fill, a slot or an op's unit placing an element stamped after `from` and at or before its own start sets `eager`; the server turns it on per level for E1257, an island's client re-render for its own E1253). `./url` (kernel packages only: compiler, ui; the one URL policy): `URL_ATTRS` (`href`, `src`, `action`, `formaction`, `xlink:href`, `poster`, `ping`, `data`, `srcset`, `imagesrcset`, `to`, `from`, `by`, `values`), `RAW_HTML_ATTRS` (`srcdoc`), `isSafeUrl(name, value) -> boolean`, `isRefusedAttr(tag, name) -> boolean`, `safeUrl(name, value) -> value | "about:blank"`. `./jsx-runtime` (types only): the `JSX` namespace for `jsxImportSource: "@keel/runtime-dom"`; where a component takes `children` only as a thunk, the children written between its tags type-check as that thunk's content, which they compile to. With a `ctx`, roots report input events (a field ever matched as a password, by type or `autocomplete`, or carrying `data-k-pii`, reports its `input` value and one-character `keydown` keys as `x` repeated) and `Match`/`Boundary` report resource states and catches to ctx observers; a `Boundary` reports every catch, observed or not, so the ctx keeps it for a later observer. `resume` reports `#k-state`'s served `route` as a `nav`, then its `error` (a failed server loader: `code` and `data.at` only).
- **Invariants:** a `text` binding whose value is a node, an array holding one, or a function renders `''` (a function's source is never written); under `mount` or `resume` with `mode: 'dev'` each such binding writes one `console.warn` starting `E1406` with its element id; a slot given an array places its items in order (k.place); every component body and every op child (`If`, `For`, `Match`/`Case`, `Boundary`, `mount`'s root) is built untracked: a reactive read while it is built is its value at build and re-renders nothing; a component updates through its bindings, the `computed`s and `effect`s it makes, and each op's own input (`when`, `each` and its keys, the tag, `reset()`). A hand-built `For` takes `each` as a getter and keys its rows by item object, the first per `key`. Each binding is one `effect` writing one DOM location, only on change. `attr`: `null`/`false` removes, `true` sets empty; URL attributes (incl. `poster`, `ping`) with a scheme outside http/https/mailto/tel in any list item (`ping`/`srcset`/`imagesrcset` split at whitespace and commas, `values` at `;`), and any `srcdoc`, become `about:blank`; an `on*` name, a `<base>` `href`, a `<meta>` `http-equiv` or `data-k` (the compiler's id stamp) binds nothing. Events: one root listener per bubbling type, innermost first, once per element across nested mounts, `stopPropagation` honored; non-bubbling types (`focus`, `blur`, `mouseenter`, `mouseleave`, `scroll`, `load`, `error`, `cancel`, `close`) bind directly. `dispose` removes nodes, listeners, subscriptions. Structural ops render before an anchor; keyed rows move. Each row/branch is a render unit created in its op's own scope (`scope.run`), disposed on removal; no per-commit nodes. `Boundary` catches render, binding, handler, and app `effect`/`computed` throws and handler rejections; fallback gets `keel.unexpected` with `data.at`, or a host element's `schema.invalid` (`InvalidValueError`, also with `data.at`) as raised; the fallback's type is `CaughtError`, the union of the two. `mount` adds a root Boundary (`<pre data-k-error>` holding `keel.unexpected`; with `mode: "dev"` the error's message; `mode` defaults to `"production"`) and calls `onError(error)` with the full error for each error it catches; each island `resume` resumes gets the same root Boundary once its claim succeeds (a throw while claiming is E1253): it catches the island's handler, binding and render throws and its own `effect`/`computed` throws (`data.at` the `data-k` stamp at the island's place, as `mount` uses its element's; `""` when there is none), on the claim and the client re-render path alike; the first is reported to the ctx as `keel.unexpected` and the island's nodes are replaced by the fallback, other islands unaffected. A handler's throw carries `data.at` the id it was registered under, else the `data-k` of its element or nearest ancestor that has one, else `""`; never a runtime `id`. `resume` claims server nodes in place (regions `<!--[-->…<!--]-->`; while an island claims, a server element with regions has an own `childNodes` without them, so compiled `childNodes[i]` reads the template's positions; an op at a fresh anchor in a fragment, as compiled outside a template, claims the next server region and its anchor instead); a mismatch re-renders that island, drops the queued events in its own nodes, warns E1253 (ending `an element was made before its parent` when the re-render placed an element made before the op placing it). Nothing claimed moves (k.claim In place): `frag` keeps each claimed element where it is and puts each text in place of the server's text there, an op's unit takes those nodes as its own, the last component slot of a template takes the elements beyond its first that a component returning several renders, a resuming `For` places no row, and an `If` resuming with no branch takes the served branch's nodes out.
- **Import-time effect (only one):** importing `./ops` adds capture listeners on `document` queueing events in unresumed islands; `resume` replays them once, in order. A queued `submit` has its default prevented at capture; after its handlers replay, unless one called `preventDefault()`, the form is submitted natively once (no second `submit` event) with the submitter's `name`/`value` and its `formaction`, `formmethod`, `formenctype` and `formtarget`; a form that left the document is not sent. A `click` inside an `a[href]` not starting `#` is not queued: the browser follows it. Every other queued event keeps the default it had when it fired (k.defaults). The generated entry imports it first. `resume` reports `#k-state`'s served `route` as the ctx's first `nav` (params and search encoded, no schemas); every `[data-k-island]` resumes, in document order, each with its own props, root Boundary and delegation root, and a `children` returning the server's content of its child level (claimed in place at its slot's region, moved by a later call, E1255 for a second call while it builds or while the content is in the document); a mismatch re-renders that island alone, and a re-rendered layout's `children` returns the held content. Per island, once it resumes, it fires a real `input` on each of its own `input`/`textarea`/single `select` whose value is off its default with no `input` queued (typed before this listener existed), in document order; once every island has resumed it replays the queued events in the order they fired, each reported to observers before dispatch and dispatched as a live one, from its target through every enclosing resumed island, innermost first, until `stopPropagation`; an event in a re-rendered island's own nodes is dropped. A layout island that mismatches before its `children` call holds the region the first `<!--k-->` comment in its element opens (the server writes one first in each child level's content). A `#k-state` snapshot with no store in `stores` waits, under `Symbol.for("keel.waitingSnapshots")` on `globalThis`, for an island to create the store of its id while it resumes, which starts from it (`@keel/store` reads it at creation); one no store took is an E1253 warning.
