# @keel/runtime-dom

**Spec:** k.runtime · **Status:** implemented · **verified:** (none)

## Contract

- **Public API:** `.`: `mount(Component, el, { ctx?, onError?, mode? }) -> dispose` · intrinsics `If`, `For`, `Match`, `Case`, `Boundary`. Types: `Component<P>` `(props, slots?, ctx?) => Node`, its second argument always `undefined` (`Slots` is `undefined`; a named slot is a prop), and `Island` the same; the runtime calls every component with `undefined` there. `./ops` (compiler and generated entry only): `template` (where `globalThis.trustedTypes` exists its HTML passes through the policy `keel`, created once per realm and shared by every runtime copy; a policy the browser refuses throws an Error naming it), `clone`, `text`, `attr`, `prop`, `on`, `cond`, `list`, `match`, `boundary`, `resume(root, components, { ctx?, stores?, mode? }) -> { warnings }`; root components get `ctx` third. `./internal` (`@keel/server` only): `serverMode` (`{ on }`: while on, every structural op and every slot other than a component slot `<!--+-->` writes its content in a region `<!--[-->` … `<!--]-->` before its anchor; k.resume) and the `E1255` message. `./url` (kernel packages only: compiler, ui; the one URL policy): `URL_ATTRS` (`href`, `src`, `action`, `formaction`, `xlink:href`, `poster`, `ping`, `data`, `srcset`, `imagesrcset`, `to`, `from`, `by`, `values`), `RAW_HTML_ATTRS` (`srcdoc`), `isSafeUrl(name, value) -> boolean`, `isRefusedAttr(tag, name) -> boolean`, `safeUrl(name, value) -> value | "about:blank"`. `./jsx-runtime` (types only): the `JSX` namespace for `jsxImportSource: "@keel/runtime-dom"`. With a `ctx`, roots report input events (a field ever matched as a password, by type or `autocomplete`, or carrying `data-k-pii`, reports its `input` value and one-character `keydown` keys as `x` repeated) and `Match`/`Boundary` report resource states and catches to ctx observers; a `Boundary` reports every catch, observed or not, so the ctx keeps it for a later observer. `resume` reports `#k-state`'s served `route` as a `nav`, then its `error` (a failed server loader: `code` and `data.at` only).
- **Invariants:** every component body and every op child (`If`, `For`, `Match`/`Case`, `Boundary`, `mount`'s root) is built untracked: a reactive read while it is built is its value at build and re-renders nothing; a component updates through its bindings, the `computed`s and `effect`s it makes, and each op's own input (`when`, `each` and its keys, the tag, `reset()`). A hand-built `For` takes `each` as a getter and keys its rows by item object, the first per `key`. Each binding is one `effect` writing one DOM location, only on change. `attr`: `null`/`false` removes, `true` sets empty; URL attributes (incl. `poster`, `ping`) with a scheme outside http/https/mailto/tel in any list item (`ping`/`srcset`/`imagesrcset` split at whitespace and commas, `values` at `;`), and any `srcdoc`, become `about:blank`; an `on*` name, a `<base>` `href`, a `<meta>` `http-equiv` or `data-k` (the compiler's id stamp) binds nothing. Events: one root listener per bubbling type, innermost first, once per element across nested mounts, `stopPropagation` honored; non-bubbling types (`focus`, `blur`, `mouseenter`, `mouseleave`, `scroll`, `load`, `error`, `cancel`, `close`) bind directly. `dispose` removes nodes, listeners, subscriptions. Structural ops render before an anchor; keyed rows move. Each row/branch is a render unit created in its op's own scope (`scope.run`), disposed on removal; no per-commit nodes. `Boundary` catches render, binding, handler, and app `effect`/`computed` throws and handler rejections; fallback gets `keel.unexpected` with `data.at`. `mount` adds a root Boundary (`<pre data-k-error>` holding `keel.unexpected`; with `mode: "dev"` the error's message; `mode` defaults to `"production"`) and calls `onError(error)` with the full error for each error it catches; each island `resume` resumes gets the same root Boundary once its claim succeeds (a throw while claiming is E1253): it catches the island's handler, binding and render throws and its own `effect`/`computed` throws (`data.at` the `data-k` stamp at the island's place, as `mount` uses its element's; `""` when there is none), on the claim and the client re-render path alike; the first is reported to the ctx as `keel.unexpected` and the island's nodes are replaced by the fallback, other islands unaffected. A handler's throw carries `data.at` the id it was registered under, else the `data-k` of its element or nearest ancestor that has one, else `""`; never a runtime `id`. `resume` claims server nodes in place (regions `<!--[-->…<!--]-->`; while an island claims, a server element with regions has an own `childNodes` without them, so compiled `childNodes[i]` reads the template's positions; an op at a fresh anchor in a fragment, as compiled outside a template, claims the next server region and its anchor instead); a mismatch re-renders that island, drops the queued events in its own nodes, warns E1253.
- **Import-time effect (only one):** importing `./ops` adds capture listeners on `document` queueing events in unresumed islands; `resume` replays them once, in order. The generated entry imports it first. `resume` reports `#k-state`'s served `route` as the ctx's first `nav` (params and search encoded, no schemas); every `[data-k-island]` resumes, in document order, each with its own props, root Boundary and delegation root, and a `children` returning the server's content of its child level (claimed in place at its slot's region, moved by a later call, E1255 for a second call while it builds or while the content is in the document); a mismatch re-renders that island alone, and a re-rendered layout's `children` returns the held content. Per island, once it resumes, it fires a real `input` on each of its own `input`/`textarea`/single `select` whose value is off its default with no `input` queued (typed before this listener existed), in document order; once every island has resumed it replays the queued events in the order they fired, each reported to observers before dispatch and dispatched as a live one, from its target through every enclosing resumed island, innermost first, until `stopPropagation`; an event in a re-rendered island's own nodes is dropped. A layout island that mismatches before its `children` call holds the region the first `<!--k-->` comment in its element opens (the server writes one first in each child level's content). A `#k-state` snapshot with no store in `stores` waits, under `Symbol.for("keel.waitingSnapshots")` on `globalThis`, for an island to create the store of its id while it resumes, which starts from it (`@keel/store` reads it at creation); one no store took is an E1253 warning.
- **Dependencies:** `@keel/reactive`, `@keel/schema`, `@keel/ctx`.
- **Rungs:** conformance; properties (seed 1337).
