# @keel/runtime-dom

**Spec:** k.runtime · **Status:** implemented · **verified:** (none)

## Contract

- **Public API:** `.`: `mount(Component, el, { ctx?, onError? }) -> dispose` · intrinsics `If`, `For`, `Match`, `Case`, `Boundary`. `./ops` (compiler and generated entry only): `template`, `clone`, `text`, `attr`, `prop`, `on`, `cond`, `list`, `match`, `boundary`, `resume(root, components, { ctx?, stores? }) -> { warnings }`; root components get `ctx` third. `./url` (kernel packages only: compiler, ui; the one URL policy): `URL_ATTRS` (`href`, `src`, `action`, `formaction`, `xlink:href`, `poster`, `ping`, `data`, `srcset`, `imagesrcset`, `to`, `from`, `by`, `values`), `RAW_HTML_ATTRS` (`srcdoc`), `isSafeUrl(name, value) -> boolean`, `isRefusedAttr(tag, name) -> boolean`, `safeUrl(name, value) -> value | "about:blank"`. `./jsx-runtime` (types only): the `JSX` namespace for `jsxImportSource: "@keel/runtime-dom"`. RFC 0070: with a `ctx`, roots report input events and `Match`/`Boundary` report resource states and catches to ctx observers; a `Boundary` reports every catch, observed or not, so the ctx keeps it for a later observer. `resume` reports `#k-state`'s served `route` as a `nav`, then its `error` (a failed server loader: `code` and `data.at` only).
- **Invariants:** each binding is one `effect` writing one DOM location, only on change. `attr`: `null`/`false` removes, `true` sets empty; URL attributes (incl. `poster`, `ping`) with a scheme outside http/https/mailto/tel in any list item (`ping`/`srcset`/`imagesrcset` split at whitespace and commas, `values` at `;`), and any `srcdoc`, become `about:blank`; an `on*` name, a `<base>` `href`, a `<meta>` `http-equiv` or `data-k` (the compiler's id stamp) binds nothing (rfc:0056, 0058). Events: one root listener per bubbling type, innermost first, once per element across nested mounts, `stopPropagation` honored; non-bubbling types bind directly. `dispose` removes nodes, listeners, subscriptions. Structural ops render before an anchor; keyed rows move. Each row/branch is a render unit created in its op's own scope (`scope.run`), disposed on removal; no per-commit nodes. `Boundary` catches render, binding, handler, and app `effect`/`computed` throws and handler rejections; fallback gets `keel.unexpected` with `data.at`. `mount` adds a root Boundary (`<pre data-k-error>`) and calls `onError(error)` for each error it catches; each island `resume` resumes gets the same root Boundary once its claim succeeds (a throw while claiming is E1253): it catches the island's handler, binding and render throws and its own `effect`/`computed` throws (`data.at` the `data-k` stamp at the island's place, as `mount` uses its element's; `""` when there is none), on the claim and the client re-render path alike; the first is reported to the ctx as `keel.unexpected` and the island's nodes are replaced by the fallback, other islands unaffected. A handler's throw carries `data.at` the id it was registered under, else the `data-k` of its element or nearest ancestor that has one, else `""`; never a runtime `id`. `resume` claims server nodes in place (regions `<!--[-->…<!--]-->`); a mismatch re-renders that island, drops its queued events, warns E1253.
- **Import-time effect (only one):** importing `./ops` adds capture listeners on `document` queueing events in unresumed islands; `resume` replays them once, in order. The generated entry imports it first. rfc:0071: `resume` reports `#k-state`'s served `route` as the ctx's first `nav` (params and search encoded, no schemas); per island it then fires a real `input` on each `input`/`textarea`/single `select` whose value is off its default with no `input` queued (typed before this listener existed), in document order, then replays the queued events, each reported to observers before dispatch.
- **Dependencies:** `@keel/reactive`, `@keel/schema`, `@keel/ctx`.
- **Rungs:** conformance; properties (seed 1337).
