# @keel/router

**Spec:** k.router · **Status:** conformance-covered · **verified:** (none)

## Contract

- **Public API:** `navigate(href: Href, opts?: { replace? }) -> Promise<void>`: navigates the router whose `App` encloses the caller, else the only one mounted (a callback's case), push or `replace`; with none or several mounted it does nothing. `manifest(routes)`: each entry is a page (`path`, `component`, optional `title(props)` whose `props.data` is typed as its loader's `output` value; k.head), a layout (`component`, no `path`) or an API route (`api: true`, `path`, a loader or actions, no `component`/`errorElement`/`title`/`layout`; k.api) -> `{ routes, href(id, params?, search?) -> Href, actions({ [id]: { POST?, PUT?, PATCH?, DELETE? } }) }` (id, params, search typed from the manifest; `routes.actions` is a statement after the manifest that attaches each path route's actions once, so an action may `return ok(routes.href(...))`, RFC 0063) · `loader({ output, params?, search? }, fn)` · `action({ input, params? }, fn)` (`fn` gets `params`/`search` as `Infer` of the declared schemas and the absolute `url`; the positional form is gone, RFC 0027) · `guard({ redirect }, fn)` -> `Guard` (fits pages, layouts and API routes) · `guard({}, fn)` -> `ApiGuard` (fits API routes only), held by reference in `guard` · `createRouter(manifest, { ctx, history }) -> { navigate(href, { replace? }), route, App, dispose }`; `route.get()` is `{ id, params, search, pending }` · `Form({ method, action: Href, form?, error? })` · `routesArtifact(manifest)` · `browserHistory()`. Types in `src/index.ts` (`Guard`, `ApiGuard`, ...). Server internals (`compileRoutes`, `compileTable`, `matchUrl`, `needsBare`, `parseSearch`, `runGuard`, `fieldsError`, `formHandle`; types `Level`, `Located`, `Match`, `Segment`, `Table`) are in `@keel/router/internal`, not public API, with `findRouter()` (the `RouterCore` rendering the calling component, else the only mounted one, else `null`: its `ctx`, `navigate(href, { replace? })`, `accepts`, `submit`; for kernel and stdlib components) and `createRouterWith(manifest, opts, state?)`: `createRouter` plus a `ServerState` (`@keel/store/internal`) that runs loaders and actions naming `stores`, each loader run and each submit one `state.request()` (an action's `ok` saves, a conflict is its `err`, `err` or a throw saves nothing, the request ends before revalidating or navigating); `renderRoute` uses it. `createRouter` passes no `state`, so a loader or action naming `stores` is `keel.unexpected` (k.server Server state). **`@keel/router/match`** (rfc:0071, public and versioned): `matchHref(routes, href) -> { id, params, search } | null` matches an href as a navigation does (static beats `:param`, params decoded by schema, failing search keys dropped; `null` when no page matches, an API route's path included, or params fail); `routes.href(id, params, search)` is its inverse. It never seals the manifest. RFC 0070: guards get `{ url, caller }` (`createRouter(..., { caller? })`, default `""`); navigations report `nav`, loader and action `err` report `error` to ctx observers.
- **Invariants:** each `manifest` validates only its own entries (throws `code` E1502-E1507, E1510 for an entry that is no page, layout or API route, E1510 for an entry whose `api` is other than `true`, E1508 for a guard without `redirect` on a page or layout; E1510 for an API route with neither loader nor action and E1508 for a guard `redirect` naming an API route on the first read of the table: `href`, matching, `createRouter`, `createApp`; E1505: `actions` in an entry; E1507: a loader schema that is not the route's own value); `routes.actions` throws E1505 (unknown or layout id, non-verb key, second attach) or E1507 (an action `params` that is not the route's own) before attaching anything and owns its table; manifests never interact. `routes.href` takes page ids only (an API id fails to compile and throws E1501) and resolves only in its own manifest; the client router matches no API route, so a link to one is a document request; `routesArtifact` marks API routes `api: true`; a router and its redirects use only their own manifest. A `Form`'s `action` is an `Href`: outside a router it is rendered as given (no table, no global state); inside one the router matches it in its own table (E1505 when that route lacks the method). `href` is deterministic, omits absent optionals, sorts search keys, throws for unknown ids. Static beats `:param`; trailing slash is canonicalized. Bad params: `keel.notFound` in the nearest `errorElement`, inside its layouts only if none has a loader or guard; no guard or loader runs. Guards outermost first; `keel.denied` redirects with `?next=`. Loaders start together after guards; the previous page stays until they settle; an `err` renders the nearest `errorElement` under its layouts. `ok(null)` reruns each chain loader once, no re-render; `ok(href)` pushes. After `navigate` to another route: focus the page's first `h1`, else `main` (`tabindex="-1"`); within one route focus stays (on the element with the same id when the page is rebuilt); then scroll to the hash target, else to the top unless only the search changed (a search-only push or replace keeps scroll); pop restores the arriving history entry's saved scroll (router-minted entry keys; `RouterHistory.push/replace(url, key)`, `onPop(fn(url, key?))`).
- **Dependencies:** `@keel/schema`, `@keel/reactive`, `@keel/runtime-dom` (`boundary`, `cond`), `@keel/ctx` (types), `@keel/store` (the `ServerState` type).
- **Rungs:** conformance; properties (seed 1337): href/match round-trip over generated manifests, static beats param, trailing slash.

## Extension points

`FormHandle` (`{ [formHandle]: FormSeam }`, `formHandle` from `@keel/router/internal`; seam `setPending`, `validate`, `onResult`): `<Form form>` calls `validate()` (an `err` stops the submit), `setPending(true)`, runs the action from FormData, `setPending(false)`, then `onResult(result)`. `Form` finds its router through the owner scope chain (the `App` scope); outside a router it is a native form. Implemented by `@keel/forms`. `RouterHistory`: any `{ push, replace, current, onPop }`.
