# Red team

Pick a recent merge. Try to: find two ways to do one thing; break a guarantee without `unsafe`; make `check` lie; exceed an output budget; write a passing test that proves nothing (verify with mutate); make replay nondeterministic. Each finding: one backlog line with a reproduction command. No prose beyond that.
