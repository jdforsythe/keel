# routes
| id | holds |
|-|-|
| k.router | route manifest, matching, links, return targets, execution, client and forms |
| k.contract | per-module contract: routes, static reading, binding, handlers, derived data |
| k.routes | deployable route table as a union of manifests, layouts, where rules fire |
| k.guards | `guard` API, home, client use, test files and carried params |
| k.prefix | implied path prefix for a second leading param value, `pathDefault` |
| k.api | JSON API routes: requests, output, bearer tokens and calling |
| std.health | health route module: manifest, route and public export |
| std.contracts | contracts for health, sessions, channels and offline, over `contract` |
