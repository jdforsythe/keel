# k.e2e-page: End-to-end pages
status: implemented
The page a `Served` handle opens (k.e2e): the harness's verbs (k.testing) on a real browser tab, and how it waits.

**open.** `open(path, { deployable?, scripts?, hold? })` loads `path` at the deployable's origin in a new browser context and resolves a `Page` once the document's `load` event has fired and the page is quiet (Waits). `scripts: false` delivers no script, and each document arrives without its script elements. With `hold: true` no script of the app runs until `resume()` but each classic external script with neither `async` nor `defer`, which runs as the parser reaches it (a `client` or `static` document's scheme script, k.schemes First paint). A `Page`'s `open(path, { hold? })` opens another tab in its own context, sharing its cookies and storage.

**Verbs.** Each verb takes ids alone (k.testing). An id is known when it is in `.keel/ids.json`, is a form field `<formId>:<path>` of a form id there (k.forms), fits the fixed head and tail of a template id its or its libraries' source writes (`` `shop.row.${row.id}` `` fits `shop.row.p1`), or is on the page when the verb is called (a widget's id composed at run time). A known id not yet shown is waited for (Waits). Any other id is E1705 at once, listing at most 3 nearest known ids by edit distance (`find shop.cart.cuont: no such id; nearest shop.cart.count`). An id under a listed id is not known for that alone. `findAll`'s `prefix` is judged the same way.
- `fire(id, event)`: `event` is k.testing's `TestEvent`, sent as a person's act: `click` a mouse click at the element's centre, `input` with `value` the element's text replaced by typing `value`, `change` with `value` the option picked, `keydown` a key press, `focus` and `blur` focus moved. It resolves once the page is quiet.
- `press(key)`: a key press at the focused element, `key` as `keydown`'s, `Tab` among them.
- `find(id)`: `{ id, role, name, text, state, value? }` as k.testing's (a host element's without `value`: its value is the runtime's, which the page does not expose), once the element is shown; not shown within the bound, E1735. `findAll(prefix)`: each shown element whose id begins `<prefix>.`, in document order, at once.
- `until(id, match, { within?, fixed? })`: resolves once `find(id)` matches `match`, `{ text?, name?, role?, state?, gone? }`: `text` a string equal to the element's text with white space runs made one space and the ends trimmed, or a `RegExp` it matches; `state` the given keys equal; `gone: true` no element with that id shown.
- `title()`: the document's title, as `document.title` reads it (k.head).
- `settle()`: resolves once the page is quiet. `focusOrder()`: the ids in tab order, as k.testing's.
- `a11y(id?)`: k.testing's tree, built in the page; then axe-core over the document with k.a11y's tags and rules, `color-contrast` among them as the browser renders it; a violation is E1703.
- `navigate(path)`, `reload()`, `back()`: as a person's address bar, reload and back, resolving as `open` does. `location()`: `{ path, entries }`, the path and query, and the tab's history length. `documents()`: `{ method, url, status }` per document the tab loaded, in order.
- `requests()`: the tab's request log (k.requests): each request the browser sent for it, documents, scripts and event streams among them.
- `cookies()`: `{ name, domain, path, httpOnly, secure, sameSite, expires }` per cookie of the context, no value.
- `fetch(path, init?)`: a request made from the test process with the context's cookies, as `Served` `fetch` otherwise; a `Set-Cookie` it answers is kept in the context.
- `offline(on)`: the context's network off or on, service workers' requests too.
- `scroll(y)`: the document scrolled to `y` CSS pixels from the top, as a person's wheel. `viewport({ width, height })`; `layout(id?)`: `{ x, y, width, height, scrollWidth, clientWidth }` of the element, or of the document with no `id`; `style(id, names)`: the computed values of `names`, each one of `color`, `background-color`, `font-family`, `font-size`, `outline-style`, `outline-width`, `outline-color`, `outline-offset`, `flex-direction`, `display`, `padding-top`, `padding-right`, `padding-bottom`, `padding-left`; with `id` `undefined`, of the `body` element. The document and its `body` have no id: `layout()` and `style(undefined, names)` read them.
- `resume({ grows? })`: on a held page, runs its scripts and resolves once every island has claimed and the page is quiet. Once the document is parsed, before any parked script runs, it records each element under each island root (an element with `data-k-island`), the root among them, and the page's `data-k-island` values. It rejects E1720 (k.testing) when, after the claim, a recorded element is no longer in the document or was replaced, an element was added under an island root, the `data-k-island` values differ, or focus, a control's value or caret, or the scroll position moved. It names the island and the first such element by id, else by tag and place (`li 3 under recipes.list`). `grows` lists ids whose elements may gain descendants during the claim. Only additions inside them are permitted: an element removed or replaced there is still E1720, and an id of `grows` not on the page is E1705. A caret is placed before `resume()` as a person places it, with `press` (`Home`, `ArrowRight`).
- `problems(...expected)`: the browser problems of the tab's context not yet taken, each `{ kind, text }`, `kind` `pageerror`, `console` (an error), `warning` (a console warning), `csp` (a policy violation), `offsite` (k.e2e-run Reach) or `dialog` (an `alert`, `confirm` or `prompt`, dismissed). Without arguments it returns all and takes none. Each `expected` is `{ kind, text }`, `text` a string the problem's text holds or a `RegExp` it matches. Called with them, it returns the problems some entry matches and takes those alone; a problem no entry matches stays.
- `upload(id, files)`: on an `<input type="file">`, picks `files` as a file dialog does, each `{ name, type }` with `text` or `bytes`, then dispatches `input` and `change`; on another element, E1726. `download(id)`: clicks `id` and resolves `{ name, type, bytes }` of the file the click downloads; no download within the bound is E1735.
- `hover(id)`: the mouse moved to the element's centre. `opened()`: a `Page` for each tab the page opened (a `target="_blank"` link, `window.open`), in order, each loaded as `open` resolves.

**Waits.** A page is quiet when no request it sent is unanswered but event streams (`text/event-stream`), no DOM change has happened for one animation frame, and no navigation is under way. Every wait above is bounded: 10 s, or `within` and `fixed` (k.e2e-run Time); a wait that runs out is E1735. A held page's parked scripts are not waited on until `resume()`. No verb sleeps; each waits on a browser event or a DOM change.

**Problems.** A test names the problems it expects. A problem no `problems(...expected)` call took by the end of the test fails it with E1738 naming the first: `pageerror Uncaught TypeError: ...`, `csp script-src blocked inline`.

**Failure output and walls.** k.e2e-run.

**Rules.** E1735 a wait of a page that ran out (`<verb> <id>: <what was seen> after <s>s`) · E1738 a browser problem the test did not read.

**Conformance.**
- `fire('a.add', { type: 'click' })` on a button whose handler posts to an action resolves after the action's answer has reached the page, and `find` then shows the text the answer set.
- `find('a.nope')` with `a.nope` absent from `.keel/ids.json` rejects E1705, and the browser receives no command for it.
- `until('a.status', { text: 'Live' })` on an element whose text is `Connecting` for the 10 s bound rejects E1735 whose message holds `a.status`, `Connecting` and `10.0s`.
- `until` with `within: 2000`, `fixed: 5000` under `KEEL_TEST_TIME_SCALE=0.5` waits 6 s before E1735.
- `settle()` on a page holding an open event stream and nothing else in flight resolves.
- `findAll('shop.row')` on a page with `shop.row.a`, `shop.row.b` and `shop.rows` returns `shop.row.a` and `shop.row.b`, in document order.
- `open('/list', { hold: true })`, `fire('a.name', { type: 'input', value: 'Mi' })`, then `resume()` keeps the input's `value` `Mi`, its caret at 2 (a `press('x')` then makes it `Mix`) and its focus, and resolves; an island whose claim replaces the input makes `resume()` reject E1720.
- After `offline(true)`, a click on a button whose handler fetches the page's origin leaves its `TypeError` among `problems()` and no entry for it in the server log; after `offline(false)` the same click is answered 200.
- `cookies()` after a form POST, the page's first write, which sets the caller cookie `keel-caller` (`HttpOnly`, `SameSite=Lax`; k.user), holds its name with `httpOnly: true` and `sameSite: 'Lax'` and no value.
- `documents()` of a page whose live update changed its text without a load holds one entry.
- A test whose page's click handler rejects with `new Error('boom')` (an unhandled rejection: app code may not `throw`, E1451), and that never calls `problems()`, fails with E1738 holding `boom`; calling `problems({ kind: 'pageerror', text: 'boom' })` after the click returns it, and the test passes; calling `problems()` with no argument returns it, and the test still fails with E1738.
- A test that fails at `until` writes one `.png` and one `.zip` under `reports/e2e/` named after its file and its T0001's line, and its T0001 output lists the `server:` records of the requests made during that `until`; the same test passing writes nothing under `reports/e2e/`.
- `a11y()` of a page whose text is `#777` on `#fff` rejects E1703 naming `color-contrast`.
- On a page whose only focusable element is `a.button`, styled `outline: 2px solid` when focused, `press('Tab')` then `style('a.button', ['outline-style', 'outline-width'])` returns `{ 'outline-style': 'solid', 'outline-width': '2px' }`.
- `title()` of a page whose route's title is `Shopping list` (k.head) returns `Shopping list`, and after `navigate` to another route, that route's title.
- `style(undefined, ['background-color', 'padding-top'])` on a page whose `body` is styled `background: #f9f9f9; padding-top: 4px` returns `{ 'background-color': 'rgb(249, 249, 249)', 'padding-top': '4px' }`.
- A page whose click handler calls `console.warn('late')` fails its test with E1738 holding `warning late` when the test does not read `problems()`, and `problems({ kind: 'warning', text: 'late' })` after the click returns `{ kind: 'warning', text: 'late' }` and the test passes.
- On a held page whose served input `a.name` holds `Milk`, `fire('a.name', { type: 'focus' })`, `press('Home')`, `press('ArrowRight')` twice, then `resume()` resolves with the caret at 2; an island whose claim drops its `data-k-island` attribute makes `resume()` reject E1720.
- On a page holding an id `shop.cart.count` and no template id, `find('shop.cart.cuont')` and `find('shop.cart.x')` each reject E1705 within 100 ms naming `shop.cart.count` as nearest; `find('shop.row.p9')` with a template id `` `shop.row.${id}` `` in source waits the bound and rejects E1735.
- A test that takes `problems({ kind: 'console', text: 'ERR_INTERNET_DISCONNECTED' })` while its page also raised a `pageerror` `late` fails with E1738 naming `late`.
- On a held page whose island `recipes.list` holds three served `li` elements without ids, a claim that removes the third makes `resume()` reject E1720 naming `li 3 under recipes.list`, and a claim that adds an element under an island root rejects E1720.
- `resume({ grows: ['app.events'] })` resolves when the claim appends elements inside `app.events`, and rejects E1720 when it removes one there or adds one outside it.
- `upload('a.file', [{ name: 'r.csv', type: 'text/csv', text: 'a,b' }])` makes the page's `change` handler read one file `r.csv` of 3 bytes, and `upload` on a button rejects E1726.
- `download('a.export')` on a link to a `text/csv` answer `x,y` resolves `{ name, type: 'text/csv', bytes }` whose bytes are `x,y`.
- A page whose click calls `alert('hi')` leaves `{ kind: 'dialog', text: 'hi' }` among `problems()` and the dialog dismissed; a `target="_blank"` link's click makes `opened()` hold one `Page` at its path.
- `find` of an id shown only inside a same-origin `<iframe>` of the page rejects E1705 `<id> is inside a frame: serve that app`.
