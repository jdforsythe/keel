# k.design-tokens: Design tokens import and set
status: implemented

`keel tokens import` brings a design tool's tokens into the app as `tokens.design.ts`; `keel tokens set` changes one value in `tokens.ts`. Both are commands of k.cli.

**Import.** `keel tokens import <file>...` reads files in the Design Tokens Community Group format (groups of tokens holding `$value`, a `$type` on the token or a group above it, `{a.b}` aliases) and writes `tokens.design.ts` whole: the line `// Written by keel tokens import; edit tokens.ts.`, then `export const designTokens = defineTokens({...})` with its import. A file `<stem>.<mode>.tokens.json` is mode `<mode>` of collection `<stem>`; other files have no mode. Modes `light` and `dark` give pairs. In a collection's other modes, the first given holds the top-level values and each further one is a theme named in lowerCamel, `when` `print` for `print`, `contrast` for `contrast` and `highContrast`, else `choice`, holding each value that differs from the top level in its scheme. Types: `color` to `color`, sRGB as its `hex` or `#rrggbb`, `hsl`, `oklab`, `oklch` and `display-p3` in k.values forms, other spaces as `oklch()` at 4 decimals (W1072); `dimension` by its path's first segment, `space` or `spacing` to `space`, `size` or `sizing` to `size`, `radius` or `borderRadius` to `radius`, `fontSize` to `fontSize`, `breakpoint` to `breakpoint`; `fontFamily` to `font`, a family with a space in `"`; `fontWeight` to `weight` (the format's names as numbers); `duration` to `motion`; `shadow`; `border`; `typography` to a `look` of `font`, `fontSize` and `weight`, each the aliased token, else a token of the look's name. Skipped with W1072: `gradient`, `number`, `cubicBezier`, `transition`, a lone `strokeStyle`, a color with alpha outside a `shadow`, any other `dimension`, a name met before, a dangling or circular alias; dropped with W1072: `lineHeight`, `letterSpacing`. A name joins its path's segments in lowerCamel, less a first segment naming its group (`color`, `colors`, `type`, `typography` or a word above). An alias takes its target's value, written `<ref>` in `border` and `shadow`. When `tokens.ts` does not import `designTokens`, the import adds it and `...designTokens.<group>` in each group and `...designTokens.themes` in `themes`, as k.looks Fix does; with no `tokens.ts`, it writes `export const tokens = designTokens;`. It prints each W1072 in the file given that holds the token, at the 1-based line and column of the opening quote of the token's `"$value"` key, or for a dropped field of that field's key inside it, then `ok tokens import <n> tokens, <m> looks, <k> themes`; a file that is not JSON or holds no `$value` is E1071, and nothing is written.

**Set.** `keel tokens set <path> <value>` sets one value in `tokens.ts`'s `tokens` literal, `<path>` `<group>/<name>`, `<group>/<name>/<scheme>`, or either after `themes/<theme>/`: it replaces the key written after the literal's last spread in that group (and theme), else adds it there, creating the group or theme as k.looks Fix does; with `<scheme>`, a value that was one string becomes a pair keeping it in the other scheme. It keeps every other property and comment, and writes nothing, as E1071, when the path has another form or the tokens would fail `TokenSchema`.

**Rules.** E1071 `keel tokens` refused (`<file> is not a design tokens file`, `<path> is not a token path`, `<path>: <value> fails TokenSchema`; fix: none) · W1072 a design token skipped or a field dropped (`<token>: <what> has no Keel group; skipped`, `<token> <field>: dropped`, `<token>: <space> as oklch`; fix: none).

**Conformance.**
- With `design/color.light.tokens.json` `{"color":{"$type":"color","text":{"$value":"#1a191e"},"surface":{"$value":"#F9F9F9"}},"space":{"$type":"dimension","2":{"$value":{"value":8,"unit":"px"}}}}` and `design/color.dark.tokens.json` the same with `text` `#F3F3F3`, `keel tokens import design/color.light.tokens.json design/color.dark.tokens.json` writes `tokens.design.ts` whose `designTokens` deep-equals `{ color: { text: { light: '#1a191e', dark: '#F3F3F3' }, surface: '#F9F9F9' }, space: { 2: '8px' } }` and prints `ok tokens import 3 tokens, 0 looks, 0 themes`.
- Adding `design/brand.base.tokens.json` `{"color":{"$type":"color","accent":{"$value":"#b8420d"}}}`, `design/brand.slate.tokens.json` with `accent` `#0B5CAD` and `design/brand.highContrast.tokens.json` with `accent` `#8B300A`, in that order, gives `color.accent` `'#b8420d'` and `themes` `{ slate: { color: { accent: '#0B5CAD' } }, highContrast: { when: 'contrast', color: { accent: '#8B300A' } } }`.
- A token `hero` of `$type` `gradient` is one W1072 at its `$value` with message `hero: gradient has no Keel group; skipped`; a `typography` token `type.heading` `{"fontFamily":"Inter","fontSize":"28px","fontWeight":600,"lineHeight":1.2}` gives `font.heading` `'Inter'`, `fontSize.heading` `'28px'`, `weight.heading` `'600'`, `look.heading` `{ font: 'heading', fontSize: 'heading', weight: 'heading' }` and one W1072 `type.heading lineHeight: dropped` at its `"lineHeight"` key; a file `{"a":1}` is one E1071 and writes no file.
- With `tokens.ts` `export const tokens = brandTokens;` and its import, the first case's import, with `surface` `#141317` in its dark file so that the focus ring clears 3:1 in both schemes (k.a11y Order and focus), makes `tokens` `defineTokens({ ...brandTokens, color: { ...brandTokens.color, ...designTokens.color }, space: { ...brandTokens.space, ...designTokens.space } })` with `defineTokens` and `designTokens` imported, `keel check` then reports none of E1807 and E1801, and a second import leaves `tokens.ts` byte for byte as it was.
- On that `tokens.ts`, `keel tokens set color/accent/dark '#8AB8F0'` adds `accent: { light: '#b8420d', dark: '#8AB8F0' }` after `...designTokens.color`, `keel tokens set themes/slate/radius/none 4px` adds `themes: { slate: { radius: { none: '4px' } } }`, a comment in the file stays, and `keel tokens set color/accent red` is one E1071 with message `color/accent: red fails TokenSchema` and writes nothing.
