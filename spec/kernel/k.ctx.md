# k.ctx: Capabilities
status: conformance-covered

**API.** `ctx.clock.now()`, `ctx.clock.after(ms, signal?): Promise<void>`, `ctx.random.float()`, `ctx.random.id(brand): Id<B>` (a v4 uuid as `s.id(brand)`; the one way to mint an id or token), `ctx.net.fetch(req)`, `ctx.storage` (k.persist), no `dispose`: only the ctx's maker ends it, with `createCtx`'s `signal` (k.owner). A real `ctx.net.fetch` whose connection is refused or reset rejects with a `TypeError` and never throws outside the returned promise. Registry: `register(name, { real, shell, sim })` with factories `(opts: { seed }) => Impl`; returns the accessor `(ctx) => Impl`, the only access path; a factory's seed derives from the ctx seed and the name; `capabilities()` lists names; re-registering the identical implementations object returns the same accessor; another duplicate is E1602. Sim mode, schedules and plans: k.sim.

**Observers.** `observe(ctx, fn): () => void` calls `fn` synchronously with each kernel event on `ctx`, in order, until the returned function runs; its throws are dropped. Events (`CtxEvent`): `{ kind: 'nav', href, route: { id, path, params, search, schemas } }` when the router starts a navigation, before guards, or `resume` restores the served route (`params`, `search` encoded; no `schemas`); a new observer first gets the current one, then the `error` events reported since it (the first 16), both replayed with `at`, their report time; `{ kind: 'fire', id, event }` when runtime-dom dispatches a `FireEvent` to element `id`, before its handlers (on a field ever `type="password"` or `autocomplete` `current-password`/`new-password`, for the rest of the ctx, an `input` value and a one-character `keydown` key are `x` repeated); `{ kind: 'resource', id, state }` when `Match` renders a resource state (`id`: its `inspect()` node id); `{ kind: 'error', error }` when a `Boundary` catches or a loader or action returns `err`; `save` and `net`, with `ctx.net.online()`: k.sync.

**Rules.** Ambient effects in app code are E1601: `Date` (`.now`, `new Date()`, `Date()`), `Temporal.Now`, `Intl.DateTimeFormat` `format()`/`formatToParts()` with no date, `performance.now`/`timeOrigin`, `Math.random`, `crypto.randomUUID`/`getRandomValues`, `setTimeout`/`setInterval`/`requestAnimationFrame`, `fetch`, `navigator.sendBeacon`, `XMLHttpRequest`/`WebSocket`/`EventSource`, `localStorage`/`sessionStorage`/`indexedDB`, `document.cookie`. Found through `globalThis`/`window`/`self`, literal computed keys (`const` strings too) and same-file bindings (aliases, parameter defaults, destructuring), by lexical scope. An alias is reported at its uses, or at its declaration when exported there. The fix is the exact `ctx` equivalent; `crypto.randomUUID` names `ctx.random.id(brand)` without a fix. E1603 `eval`, `Function(...)` or `new Function(...)` in app code, also aliased or as a function's (or its prototype's) `constructor`, and `import()` or `new Worker`/`SharedWorker` (also `Reflect.construct`) of a `data:` or `blob:` URL. E1603 follows a URL through `String()`, templates, `+`, `new URL`, `?:`, object literal properties and each value assigned to a local, and a function's prototype chain to its `constructor`. Neither follows values through calls or files, nor E1601 through object literals or a reassigned binding. W1608 an `import()` expression in app code, at `import`, whatever its specifier (a literal, a template, any expression) and however its result is used (`await`, `.then`, discarded): a module load is I/O no ctx owns, so a `simulate` run (k.sim) neither waits for it nor orders it by seed. Not reported: an `import()` that is E1603; a `Host`'s `code` written as its prop value in E1824's form, `() => import('<path>').then((m) => m.<export>)` (the harness never runs it, k.host-element); a message set's `load`, the arrow function whose body is the `import()`, written as the third argument of a call whose callee is the `messages` import of `@keel/std-messages` (E2401 fixes its form). Test code is not app code, so the harness's `routes: () => import(path)` (k.testing) is not judged; a type (`typeof import('./a.ts')`) holds no `import()` expression. W1608 is a warning: it never fails `keel check` (k.check Diagnostics). No fix.

**Conformance.**
- `after(ms)` under sim resolves exactly when `advance` crosses the deadline, never before, and an aborted waiter rejects.
- `random.id(brand)` under sim is deterministic by seed and parses with `s.id(brand)`; `random` has no `uuid`.
- Ctxs created before and after `register(name)` both reach it in real, shell, and sim.
- Simulated implementations are deterministic by seed.
- Every capability has all three implementations.
- In `keel test`, a ctx created with no options is sim, with seed 0.
- `const D = Date; D.now()`, `` Date[`now`]() ``, and `const { random } = Math; random()` are each one E1601, at the call; after `const Date = ctx.clock`, `Date.now()` is not E1601.
- For an alias chain of depth 1 to 4 to `Date.now` or `Math.random`, E1601 is reported exactly once, at the call.
- `eval(s)`, `Function(s)`, `new Function(s)`, and `const e = eval; e(s)` are each one E1603; a locally declared `Function` is not.
- `Temporal.Now.instant()`, `performance.timeOrigin`, `navigator.sendBeacon(u, b)`, and `new Intl.DateTimeFormat('en').format()` are each one E1601; `.format(d)` is not.
- `(() => {}).constructor(s)`, `(async () => {}).constructor(s)`, `Function.prototype.constructor(s)`, and `import('data:text/javascript,' + s)` are each one E1603; `import('./a.ts')` is not.
- `import(URL.createObjectURL(b))`, `new Worker(URL.createObjectURL(b))`, `new Worker('data:,' + s)`, and `Object.getPrototypeOf(async function () {}).constructor(s)` are each one E1603; `new Worker('/w.js')` is not.
- `import(String(URL.createObjectURL(b)))`, `` import(`${URL.createObjectURL(b)}`) ``, `new Worker(new URL(URL.createObjectURL(b)))`, `Reflect.construct(Worker, [URL.createObjectURL(b)])`, `import(u)` after `let u; u = URL.createObjectURL(b)`, and `Object.getPrototypeOf(Object.getPrototypeOf(async () => {})).constructor(s)` are each one E1603; `new Worker(new URL('./w.js', import.meta.url))` is not.
- In `modules/m/a.ts`, `import('./b.ts')`, `` import(`./${n}.ts`) ``, `import(name)`, `await import('./b.ts')`, `void import('./b.ts')` and `import('./b.ts').then((m) => m.b)` are each one W1608, at `import`; `import { b } from './b.ts'`, `export { b } from './b.ts'` and `type B = typeof import('./b.ts')` are none.
- `import('data:text/javascript,' + s)` in `modules/m/a.ts` is one E1603 and no W1608; `import('./b.ts')` in `modules/m/a.test.ts`, in `test/h.ts` and in `vite.config.ts` is no W1608.
- In `modules/m/C.tsx`, a `Host` imported from `@keel/ui` with `code={() => import('./c.ts').then((m) => m.c)}` gives no W1608; with `code={load}` after `const load = () => import('./c.ts').then((m) => m.c)` it gives one W1608, at that `import`.
- In `modules/m/MText.schema.ts`, ``messages(Locale, keys, (locale) => import(`./MText/${locale}.ts`))`` with `messages` imported from `@keel/std-messages` gives no W1608; the same call with `messages` declared in the file, or with that arrow function held in a `const` passed as the third argument, gives one W1608.
- In `modules/m/unsafe/a.ts`, `import('./b.ts')` inside the arrow function given to `unsafe('r', () => ...)` is no W1608, and inside a function declared at that file's top level is one W1608.
- Under a sim ctx, a navigation, a `fire`, a resource state and a `Boundary` catch each reach `observe` once, in order; a password field's `input` value arrives as `x` repeated, also after its `type` changes; an observer added after a navigation gets it first, one that throws stops no other, and none gets an event after its stop function runs.
- An `error` reported while nothing observes reaches a later observer right after the current `nav`, at most the first 16 since it; one reported before a later `nav` does not.
- A replayed `nav` or `error` carries `at`, its report time; a live one has none.
- `seedOf(ctx)` is the seed given to `createCtx`, and `undefined` when none was given.
- A real `ctx.net.fetch` to a port nothing listens on, and to a server that resets the connection as it is set up, each rejects with a `TypeError`, with no uncaught exception.
- Under a stub `window`, aborting the `signal` a real ctx was made with removes its `online` and `offline` listeners once each; a second abort removes nothing.
