# k.openapi: OpenAPI import
status: conformance-covered

**API.** `openapi(doc, { name })` from `@keel/services/openapi` (build time; `keel scaffold service` writes its output) returns `Result<{ schema, service }, SchemaError>`: the sources of `<Name>Api.schema.ts` (`<Name>Api = endpoints({...})`, one endpoint per operation keyed by its `operationId`, in document order) and `api.ts` (`api = service({ base: servers[0].url, schema })`, importing `./<Name>Api.schema.ts`). Each file's name equals its one export (principle 3, E1752). From OpenAPI 3 JSON: `{name}` path segments become `:name`; `path` and `query` parameters become `params` and `query` objects (query fields optional unless `required`); a JSON request body is `body`; the lowest 2xx JSON response is `output` (none: `s.json()`); every other numeric status with a JSON body is in `errors`. Schemas: `string` (`minLength`/`maxLength`), `integer` and `number` (`minimum`/`maximum`), `boolean`, `array`, `object` (keys outside `required` optional; `additionalProperties: false` closes it; `additionalProperties` alone is `record`), string `enum`, `const`, `nullable: true` or `type: [T, 'null']`, `oneOf`/`anyOf` (member union), local refs (`#/components/schemas/<Name>` becomes a file-local `const <Name>`, others are inlined); anything else is `s.json()`. A doc outside this subset (no `paths`, a missing or non-identifier `operationId`, a missing or relative server URL, a cyclic ref) is `err`, with issue paths into the doc.

**Conformance.**
- The client generated from the OpenAPI fixture has one method per operation, with input and output types matching it.
