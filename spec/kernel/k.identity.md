# k.identity: Identity and proven predicates
status: implemented

**Identity.** What proves that a value is a loader, an action, a guard, a route table, a server-only stub, a schema, a store, a transaction, a `Secret` or a defect is the kernel's own record of what its makers made: a `WeakSet`, or a `WeakMap` where the maker records more, kept in the realm's kernel record, one per realm, shared by every copy of a kernel package loaded in it and exported by no entry. No property of the value carries identity: nothing a caller can write, copy, spread or enumerate.
- The guards: `isSchema`, `isObjectSchema`, `isDefect` (`@keel/schema`), `isStore`, `isTransaction` (`@keel/store`), `isRouteTable` (`@keel/router`). Each is true only of a value its maker returned in this realm.
- A made value is frozen. A copy is not that thing: a spread, `Object.assign`, `structuredClone`, a `Proxy` over it, and an object given each of its own keys and descriptors, symbol keys among them, fail every guard.
- Where the kernel binds a handler (`manifest`, `createApp`, `createRouter`), a value no maker made is E1515, naming the route id and the member; nothing runs it.
- A wrapper wraps the function before the maker has it: `action(c, id, decl, timed(fn))`. No call wraps a made value, since a second way to make an action would need the same record.

**What the kernel reads.** A maker records, with the identity, what it was made from: the contract entry (k.contract), an action's `input` (an API write's `body` from the entry, a page action's `decl.input`), a loader's `output`, and a copy of `decl`. The server decodes a request's input, encodes its output and builds the request's personal-data set (k.privacy Server log) from that record, never from a property read off the value it was handed. So neither a forged value nor a `decl` changed after the maker returned changes what is decoded or what the log scrubs.

**Secret.** A `Secret`'s class has no static member, and the constructor reached from an instance (`Object.getPrototypeOf(v).constructor`) is the defect E1764 when called. Sealing and opening are functions private to `@keel/schema`; `reveal` is the only read (k.reveal), and only a `secret` node's parse makes one.

**Proven predicates.** A function whose return type is a type predicate (`x is T`) or an assertion (`asserts x is T`, `asserts x`) tells the type checker what its body has proven. A body that does not establish `T` is a cast nothing counts, so E1762 accepts a closed set of proofs and reports every other body. The body is `return P` (an arrow's expression), or for an assertion `if (!(P)) defect(...)`; `P` is an `&&` chain, and `T` is established when a conjunct is one of:
1. Identity: a call `g(x)` of a predicate that itself proves a type assignable to `T`: a kernel guard, or one this rule accepts, read at its declaration.
2. An owned class: `x instanceof C`, `C` a class the package declares or a built-in, for `T` the class with every type argument `unknown`.
3. The module's own set: `B.has(x)`, `B` a module-level `const` `WeakSet` the file neither exports nor passes, assigns or returns, where every `B.add(v)` of the file has `v` of a type assignable to `T`.
4. A schema: `S.parse(x).ok`, for `T` `s.infer<typeof S>` or wider.
5. Structure, only for a `T` with no call or construct signature at any depth and no type parameter of the predicate: `typeof x === '<primitive>'`; `x === <literal>` and `x === null`; `||` over a union's members; for an object type, `typeof x === 'object' && x !== null` and then, for each required property `p` of `T`, a conjunct that establishes `p`'s type on `x.p` (or `Reflect.get(x, 'p')`) by any of these five, to the depth `T` names; an optional `p` as `x.p === undefined || ...`; an array as `Array.isArray(x.p) && x.p.every(q)`, `q` a proven predicate of the element type; a property typed `unknown` as `'p' in x`.

A `T` holding a signature is proven only by 1, 2 or 3: `typeof v === 'function'` proves that a value can be called, which is all `() => void` claims, and no signature beyond it. A type parameter of the predicate is proven only through 1 or 4, by a predicate or schema typed over the same parameter. `typeof x === 'object'` proves no property; an empty assertion proves nothing; `x instanceof Promise` proves `Promise<unknown>`, never `Promise<number>`.

**What stays `unsafe`.** A claim no check establishes is a cast in an `unsafe(` call, counted (k.unsafe): a function's signature known only from a type (`callable<F>`), a type argument (`Outcome<V>`), a platform object of another realm read by its shape (a `Node` of the server's document, a `FormData`). `keel review` lists each predicate proven by 3 or 5 (R1015) for a person to read.

**Rules.** E1762 a type predicate or assertion function, its declaration or arrow function, whose body is no proof above, at the return type, message `type predicate claims <what> it does not prove: check it, or use unsafe()` (`<what>` the first of: `property <p>`, `a call signature`, `a type parameter`, `a type argument`, `its whole type`), in app code and a library's files outside lifted ranges and, in this repository, in every package's `src/` (`tooling/structure-lint.mjs` S0019, same position and message), no fix · E1515 (k.server) also a bound handler no maker made · E1764 the `Secret` constructor called outside `@keel/schema`, a defect.

**Conformance.**
- With `a = action(c, 'p.b', { input: A }, run)` and `A`, `B` object schemas: `Object.isFrozen(a)` is true, and `manifest` given `{ ...a }`, `{ ...a, input: B }`, `Object.assign(Object.create(Object.getPrototypeOf(a)), a)`, an object given every `Reflect.ownKeys(a)` key with its descriptor, or `new Proxy(a, {})` in `a`'s place throws a value whose message starts `E1515` and names `p.b`, and runs nothing; the same holds of a `loader`'s and a `guard`'s copies.
- With `decl = { input: A }`, `a = action(c, 'p.b', decl, run)` and `A.email` a `.pii()` string: after `decl.input = B` (an untyped write), a POST whose body holds `email=jane@x.com` and whose `run` throws is decoded by `A`, and no log line holds `jane@x.com`.
- `createApp` and `createRouter` given routes in which a copy of an action, made as the first clause makes one, stands for it throw a value whose message starts `E1515` and names the route id and the member, and run nothing.
- `isDefect`, `isSchema`, `isStore`, `isTransaction` and `isRouteTable` are each false of `structuredClone` of a value it is true of, where the clone can be made, and of `new Proxy(v, {})`.
- `isSchema(S)`, `isStore(st)`, `isTransaction(tx)` and `isRouteTable(routes)` are true of what `s.object`, `store`, `transaction` and `manifest` returned, also under a second copy of the guard's package loaded from another path; each is false of `{ ...v }`, of an object given every own key and descriptor of `v`, and of a function or object declaring `Symbol.for('keel.schema')`, `Symbol.for('keel.store')` or `Symbol.for('keel.action')` as an own key.
- For `v` a parsed `s.secret(s.string())` value, `Object.getOwnPropertyNames(Object.getPrototypeOf(v).constructor)` is `length`, `name` and `prototype` in some order, calling that constructor with `new` throws a value `isDefect(v, 'E1764')` accepts, and no export of `@keel/schema` but `reveal` returns the string.
- In `modules/m/a.ts`, each of these is one E1762 at the return type: `(x: unknown): x is { admin: boolean } => typeof x === 'object' && x !== null` (`property admin`); `function a(x: unknown): asserts x is { admin: true } {}` (`its whole type`); `(x: unknown): x is Promise<number> => x instanceof Promise` (`a type argument`); `(x: unknown): x is Map<string, () => number> => x instanceof Map` (`a type argument`); `(x: unknown): x is { run(n: number): string } => typeof x === 'object' && x !== null && typeof Reflect.get(x, 'run') === 'function'` (`a call signature`); `function isE<E>(x: unknown): x is Box<E> { return true }` (`a type parameter`); and a predicate claiming `Store<unknown>` by `Object.hasOwn(x, Symbol.for('keel.store'))` (`a call signature`).
- In `modules/m/a.ts`, each of these is no E1762: `(x: unknown): x is { id: string; tags: string[] } => typeof x === 'object' && x !== null && typeof Reflect.get(x, 'id') === 'string' && Array.isArray(Reflect.get(x, 'tags')) && Reflect.get(x, 'tags').every(isString)` with `isString` proven by `typeof`; `(x: unknown): x is User => User.parse(x).ok`; `(x: unknown): x is Store<unknown> => isStore(x)`; `(x: unknown): x is Map<unknown, unknown> => x instanceof Map`; `(x: unknown): x is Job => x instanceof Job` with `class Job` in the file; `(x: unknown): x is () => void => typeof x === 'function'`; `function isOf<T>(S: Schema<T>, x: unknown): x is T { return S.parse(x).ok }`; and `function a(x: unknown): asserts x is string { if (!(typeof x === 'string')) defect('no string') }`.
- With `const made = new WeakSet<object>()` at module level and `function make(): Job { const j = build(); made.add(j); return j }`, `(x: unknown): x is Job => typeof x === 'object' && x !== null && made.has(x)` is no E1762; with `export const made`, with `register(made)` anywhere in the file, or with a second `made.add(v)` whose `v` is typed `object`, it is one.
- `keel review` reports one R1015 for a predicate proven by structure or by the module's own set, and none for one proven by a kernel guard, a class or a schema.
