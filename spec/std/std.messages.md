# std.messages: Message sets
status: conformance-covered

**Extension points.** Schema type registry (k.formats `s.format`; message types are not registered, each depends on its key's params). Check rule registry (k.check `defineRule`): `@keel/std-messages/tools`, which `keel check` imports for a module whose `deps` list the package, registers E2401 to E2407. It depends on `@keel/std-i18n` for `Locale`, `formatNumber` and `plural`.

**API** (`@keel/std-messages`; client-safe, no config).
```ts
// RecipesText.schema.ts: keys and params, declared once
export const RecipesText = messages(AppLocale, { title: {}, count: { n: s.int({ min: 0 }) } },
  (locale) => import(`./RecipesText/${locale}.ts`))
// RecipesText/de-DE.ts: one file per locale
export default RecipesText.text({ title: 'Rezepte', count: { plural: 'n', '=0': 'Noch keine Rezepte', one: '# Rezept', other: '# Rezepte' } })
// loadIndex.server.ts
return ok({ recipes, text: await RecipesText.load(params.locale) })
// RecipeList.tsx
<Heading id="recipes.list.title" level={1}>{props.data.text.title}</Heading>
<Text id="recipes.count">{formatMessage(props.data.text.count, { n }, props.params.locale)}</Text>
```
- `messages(locales, keys, load)` declares a message set in a `*.schema.ts` file. `locales` is the app's `s.enum` of `Locale` tags. `keys` maps each key (an identifier) to its params: schemas that are `s.string()`, a `line` or `para`, `s.int()`, `s.number()` or `s.enum()`; any other throws. `load` is ``(locale) => import(`./<Set>/${locale}.ts`)``, `<Set>` the export's name. The set is a closed object schema of one locale's entry, with `text` and `load`.
- An entry gives every key a message. A key without params takes text: 1 to 2,000 characters, one outside `White_Space`, with no `{` or `}`. A key with params takes an object: `{ text }`, one template; `{ plural: p, other, zero?, one?, two?, few?, many?, '=n'? }`, templates chosen by the number param `p` (Plurals); or `{ select: p, cases }`, a template for each value of the enum param `p`. A template writes a param as `{name}`, a name its key declares; in a plural form `#` is `p`. Each message is a format type (rule `format` when it breaks this), so `parse`, `gen` and `doc()` derive from the set.
- **Plurals.** A plural message holds category forms, `other` and any of `zero`, `one`, `two`, `few` and `many`, and exact forms. An exact form's key is `=` and a non-negative safe integer in decimal digits, with no sign, point, exponent or leading zero (`'=0'`, `'=1'`, `'=12'`); any other key starting with `=` fails with rule `format`. An exact form applies when `params[p]` is its number; otherwise the category `Intl.PluralRules` selects for the locale, else `other`. A category form applies only where the locale's rules select that category: no supported locale selects `zero`, `two` or `few`, and `ja-JP`, `ko-KR` and `zh-CN` select `other` alone, so "none yet" is `'=0'`.
- `Set.text(entry)` returns `entry` typed as the set's entry; it is a locale file's default export. `Set.load(locale): Promise<Entry>` imports that locale's file through `load` and parses its default export with the set; a failing entry throws (unexpected).
- `formatMessage(message, params, locale): string` renders an object message, `params` typed by its key: `{name}` becomes the param, a number through `formatNumber`; `plural` goes through `plural` (std.i18n) with `params[p]`; `select` takes `cases[params[p]]`. A text message is a string and renders as itself; an object is not a `Child` (k.ui), so an object message renders only through `formatMessage`.
- Text reaches a component as loader data: a loader returns `await Set.load(params.locale)` in its output (the set is a schema) and the component reads `props.data`. A route level with no island ships no message; an island level ships the one entry in its props in `#k-state` (k.runtime), and resume keeps the server's text. In a `client` deployable `load` fetches only the active locale's file, a chunk of its own. A test pins text through `renderRoute` `params`, or passes `await Set.load(l)` in `render` props; a session replays the `nav` and its loaders.

**Rules** (in a module whose `deps` list `@keel/std-messages`). E2401 a locale of the set without `<Set>/<locale>.ts`, or `load` not that exact import (fix: the exact `load`, for the `load` form only; a missing locale file reports E2401 with no fix, because a rule's fix edits only the checked file) · E2402 a locale file without a declared key (no fix: a translation cannot be derived) · E2403 a locale file key the set does not declare (fix: removes it) · E2404 a declared key no other project file reads as `.<key>` (fix: removes it from the declaration) · E2405 a template's `{name}`, `plural` or `select` that does not match its key's params (fix: renames the placeholder when exactly one declared param is absent from that template) · E2406 a JSX text child, a string literal `label` or `alt`, or a string literal a route `title` returns (k.head), containing a letter, in a component or `routes.ts` file (no fix) · E2407 a plural form in a locale file that never applies: a category form the file's locale never selects (`new Intl.PluralRules(<locale>).resolvedOptions().pluralCategories` lacks it), or a key starting with `=` that is not an exact form (fix: `zero` becomes `'=0'`, or is removed beside an `'=0'`; another never-selected category form is removed; none for a malformed `=` key). Its messages: `plural form many never applies in de-DE`, with `; '=0' matches 0` added when the dead form is `zero` and the entry has no `'=0'` form, and `'=01' is not an exact plural form: = then a whole number, as '=0'`.

**Conformance.**
- For a fixture set with keys `title` (no params), `count` (`n: s.int()`) and `kind` (`k: s.enum(['a', 'b'])`), every `gen` entry parses and round-trips; `title: 'a{b'`, a template naming `{x}`, a `plural` on `k` and a `select` without case `b` each fail with rule `format` at the key's path; a missing key fails with `required`, an extra one with `unknown-key`.
- `messages` throws for a param schema `s.object({})`.
- In that fixture, `count` with `'=0'` or `'=12'` beside `other` parses; with `'=01'`, `'=-1'`, `'=1.5'`, `'=1e3'`, `'= 1'` or `'=x'` it fails with rule `format` at the key's path.
- `formatMessage({ plural: 'n', one: '# recipe', other: '# recipes' }, { n: 2 }, 'en-US')` is `2 recipes`; `{ text: 'Added {date}' }` with `{ date: 'November 10, 2026' }` is `Added November 10, 2026`; `{ text: '{n} items' }` with `{ n: 1234 }` in `de-DE` is `1.234 items`; a `select` gives the case of the param's value.
- `formatMessage({ plural: 'n', '=0': 'No receipts yet', one: '# receipt', other: '# receipts' }, { n }, l)` is `No receipts yet` for `n` 0 and `1 receipt` for 1 in `en-US`, and `No receipts yet` for 0 and `5 receipts` for 5 in `de-DE` and `ja-JP`; `{ plural: 'n', zero: 'none', other: '# receipts' }` with `n` 0 is `0 receipts` in `en-US`; `'=1': 'One receipt'` beside `one` gives `One receipt` for 1; `'=3': '# of 3'` gives `3 of 3` for 3.
- For every generated entry and params, `formatMessage` of each object message returns a string with no `{`.
- `Set.load('de-DE')` resolves to the fixture's `de-DE` entry; for a locale file failing the set it rejects.
- A `client` build of a fixture route whose loader loads a set holds each locale's entry in its own chunk, and no other chunk holds an entry's text.
- A node document holds a static level's message text and no `#k-state` entry for it; an island level's `#k-state` holds the served locale's entry and no other locale's text.
- E2401 to E2407 each have a triggering fixture and a clean one; E2407 triggers for `zero` in `en-US`, `one` in `ja-JP` and `'=01'`, and not for `many` in `fr-FR` or `'=0'`; the fixes of E2401 (`load` form), E2403, E2404, E2405 and E2407 apply with `git apply`, and re-checking reports no diagnostic of that code.
- The package root imports neither `@keel/check` nor `typescript`; `@keel/std-messages/tools` exports the seven rules.
