k.schema
- import { s, ok, err, attempt, type Result } from '@keel/schema'
- s.string({ min, max }) s.number({ min, max }) s.int({ min, max }) s.boolean() s.literal(v) s.enum([...]) s.id('Brand') s.object({...}) s.array(T) s.union('tag', variants) s.record(T) s.json()
- .optional() = key may be absent; .nullable() = value may be null; distinct
- type T = s.infer<typeof T>; T.parse(x): Result<T, SchemaError> (parses JSON from T.encode too; there is no decode); T.decodeStrings(FormData | URLSearchParams); gen(T) from '@keel/schema/gen'
- schemas live only in *.schema.ts, one export per file

k.errors
- Result<T,E> = { ok: true, value } | { ok: false, error }; ok(v) / err(e); narrow on r.ok
- KeelError { code, message, data }; kernel codes keel.notFound keel.denied keel.fields keel.conflict keel.unexpected schema.invalid
- no throw (E1451), no try/catch or .catch() (E1452, use attempt), no discarded Result (E1453)

k.reactive
- signal(v), computed(fn), effect(fn, { writes: [] }), resource(fetcher); resource consumed only via Match (E1204); primitives outside a scope E1203

k.store
- import { store, transaction, tx, invariant, type Store } from '@keel/store'
- store(Schema, initial, { id: 'todos.board' }); transaction(store, 'todos.addTodo', PayloadSchema, (state, payload) => next) is pure (E1302: no ctx, no globals)
- invariant(store, (state) => boolean), declared once beside the store; a violating tx returns err store.invariant and rolls back
- reads store.get(key), store.select(fn); writes only tx(t, payload, { meta }?) -> Result; store.log(), undo(), undoWhere(pred), snapshot(), restore(snap)
- a component that calls tx exports uses = [t] (E1301 otherwise); loaders and actions are unrestricted

- Date.now, new Date(), Math.random, crypto.randomUUID, bare fetch, localStorage in app code: E1601

k.router
- import { manifest, guard, loader, action, Form, type Href } from '@keel/router'
- routes.ts: export const routes = manifest({ 'todos.shell': { component: AppShell }, 'todos.edit': { path: '/lists/:listId/todos/:todoId/edit', params: TodoParams, loader: loadTodo, component: EditTodoPage, layout: 'todos.shell', errorElement: ListError, guard: editable } }); then routes.actions({ 'todos.edit': { POST: updateTodo } }) (a statement; actions are never in an entry: E1505)
- entry without path = layout, renders {props.children?.()}; a static segment beats :param
- component receives { params, search, data } (data = loader ok value); errorElement receives { error: KeelError }
- links: routes.href(id, params?, search?) -> Href, typed by the manifest; Link to, navigate, Form action take Href only (E1501)
- guards: export const editable = guard({ redirect: 'todos.index' }, async ({ url }, ctx) => ok(null) | err({ code: 'keel.denied', message, data: null })); file *.guard.ts; the route holds the value (guard: editable)
- route() { id, params, search, pending }; navigate(href, { replace? })
- <Form method="POST" action={routes.href(...)} form? error?>: ok(href) navigates, ok(null) revalidates the chain's loaders
- client deployable: the router runs guards, loaders and actions in the browser
- E1502 duplicate path, E1503 :param without params field, E1504 required search field, E1505 undeclared verb, E1506 unknown layout, E1507 params/search typed by hand

k.server (declarations, run in the browser by a client deployable)
- loader({ output, params?, search? }, fn): fn({ params, search, url }, ctx) -> Promise<Result<T, KeelError>>
- action({ input, params? }, fn): fn(input, { params, url }, ctx) -> Result<Href | null, KeelError>; return a link as `ok(routes.href(...))`
- both only in *.server.ts (E1551); params/search are the route's own schemas; never annotate fn; the client router refuses `stores`
- topology.ts: import { topology } from '@keel/server'; export default topology({ web: { modules: ['todos'], adapter: 'client' } }); the compiler generates the mount entry; ctx is createCtx({ mode: 'real' })

k.services
- import { endpoints, service } from '@keel/services'; endpoints in a *.service.ts file, output schemas in *.schema.ts
- export const suggestions = endpoints({ list: { method: 'GET', path: '/api/suggestions', output: SuggestionsReply } })
- service({ base: location.origin, schema }) built per call in a component; await api.list({}, ctx) -> Result<Output, ApiError>; never throws; requests go through ctx.net.fetch, so tests fake them with sim ctx.net.route
- ApiError: api.status { status, body }, api.network, api.timeout, api.decode, api.input
- ctx.net.fetch in app code is E1651 (declare an endpoint); E1652 :param without params field; E1653 body on GET

k.forms
- import { form } from '@keel/forms'; const f = form(TodoDraft, { initial?, id? }) in a component; f.field('title') f.values() f.errors() f.pending() f.reset()
- field id is `<formId>:<path>` (default formId `form-<hash>`), its error element `<formId>:<path>:error`; find it from r.a11y() by label
- <Form method="POST" action={routes.href('todos.list', { listId })} form={f} error={(e) => <Text>{e.message}</Text>}><Input field={f.field('title')} label="Title" /><Button id="todos.addTodo" type="submit">Add</Button></Form>
- number fields coerce from input text; invalid submit sends nothing, sets every error, focuses the first invalid field
- action err keel.fields { [path]: message } sets exactly those errors; other err renders the error slot
- E1901 input in a Form without field; E1902 unknown path
