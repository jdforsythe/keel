k.schema
- import { s, ok, err, attempt, type Result } from '@keel/schema'
- s.string({ min, max }) s.number({ min, max }) s.int({ min, max }) s.boolean() s.literal(v) s.enum([...]) s.id('Brand') s.object({...}) s.array(T) s.union('tag', variants) s.record(T) s.json()
- .optional() = key may be absent; .nullable() = value may be null; distinct
- type T = s.infer<typeof T>; T.parse(x): Result<T, SchemaError> (parses JSON from T.encode too; there is no decode); T.decodeStrings(FormData | URLSearchParams); gen(T) from '@keel/schema/gen'
- schemas live only in *.schema.ts, one export per file

k.errors
- Result<T,E> = { ok: true, value } | { ok: false, error }; ok(v) / err(e); narrow on r.ok
- KeelError { code, message, data }; kernel codes keel.notFound keel.denied keel.fields keel.conflict keel.unexpected schema.invalid
- no throw (E1451), no try/catch or .catch() (E1452, use attempt), no discarded Result (E1453)

k.reactive
- signal(v), computed(fn), effect(fn, { writes: [] }), resource(fetcher); resource consumed only via Match (E1204); primitives outside a scope E1203

k.store
- import { store, transaction, tx, invariant, type Store } from '@keel/store'
- store(Schema, initial, { id: 'kitchen.box' }); transaction(store, 'kitchen.addRecipe', PayloadSchema, (state, payload) => next) is pure (E1302: no ctx, no globals)
- invariant(store, (state) => boolean), declared once beside the store; a violating tx returns err store.invariant and rolls back
- reads store.get(key), store.select(fn); writes only tx(t, payload, { meta }?) -> Result; store.log(), undo(), undoWhere(pred), snapshot(), restore(snap)
- a component that calls tx exports uses = [t] (E1301 otherwise); loaders and actions are unrestricted

k.router
- import { manifest, guard, loader, action, Form, type Href } from '@keel/router'
- routes.ts: export const routes = manifest({ 'recipes.shell': { component: BoxShell }, 'recipes.show': { path: '/recipes/:recipeId', params: RecipeParams, loader: loadRecipe, actions: { POST: favoriteRecipe }, component: RecipePage, layout: 'recipes.shell', errorElement: RecipeError, guard: cook } })
- entry without path = layout, renders {props.children?.()}; a static segment beats :param
- component receives { params, search, data } (data = loader ok value); errorElement receives { error: KeelError }
- links: routes.href(id, params?, search?) -> Href, typed by the manifest; Link to, navigate, Form action take Href only (E1501)
- guards: export const cook = guard({ redirect: 'recipes.index' }, async ({ url }, ctx) => ok(null) | err({ code: 'keel.denied', message, data: null })); file *.guard.ts; the route holds the value (guard: cook)
- route() { id, params, search, pending }; navigate(href, { replace? })
- <Form method="POST" action={routes.href(...)} form? error?>: ok(href) navigates, ok(null) revalidates the chain's loaders
- client deployable: the router runs guards, loaders and actions in the browser; it refuses `stores`
- E1502 duplicate path, E1503 :param without params field, E1504 required search field, E1505 undeclared verb, E1506 unknown layout, E1507 params/search typed by hand

k.server
- loader({ output, params?, search?, stores? }, fn): fn({ params, search, url, caller, stores }, ctx) -> Promise<Result<T, KeelError>>
- action({ input, params?, stores? }, fn): fn(input, { params, url, caller, stores }, ctx) -> Result<Href | null, KeelError>; return a link as `const to: Href = routes.href(...); return ok(to)`
- both only in *.server.ts (E1551); params/search are the route's own schemas; never annotate fn; url is absolute; server code never reads location
- stores: a factory (ctx?) => S of stores (explicit ids) and transactions bound to them; per request it runs once, its stores restore from ctx.storage `keel.store.<id>`; an action's ok saves them (409 keel.conflict if another request saved first); err saves nothing
- topology.ts: import { topology } from '@keel/server'; export default topology({ web: { modules: ['recipes'], adapter: 'client' }, api: { modules: ['kitchen'], adapter: 'node' } }); a module is in one deployable (E1552)
- createApp({ topology, routes, ctx, deployable: 'api' }) from '@keel/server' -> Promise<{ fetch(req) }>
- writes pass the same-site check: send accept: application/json with x-keel: 1 (a services client does)
- JSON body (content-type application/json) decodes with the action input schema; fail: 422 keel.fields, action not called
- runtime JSON (accept: application/json): GET -> { id: routeId, results: { [routeId]: { ok: true, value } } }; action -> { ok: true, value: null | href } or { ok: false, error: { code, message, data } }
- status: keel.notFound 404, keel.denied 403, keel.fields 422, keel.conflict 409, other err 400
- a route may be action-only; component still required (api components: plain .ts, `export default function KitchenApi(): Node { return Box({ id: 'kitchen.api', children: 'api' }) }`)

k.services
- import { endpoints, service } from '@keel/services'; endpoints in a *.service.ts file, body/output schemas in *.schema.ts
- export const kitchen = endpoints({ box: { method: 'GET', path: '/api/recipes', output: BoxReply }, add: { method: 'POST', path: '/api/recipes', body: RecipeDraft, output: ActionReply, errors: { 422: FieldsReply } }, favorite: { method: 'POST', path: '/api/recipes/:recipeId/favorite', params: RecipeParams, output: ActionReply, errors: { 404: ErrorReply } } })
- service({ base, schema }) built per call (base new URL(url).origin in *.server.ts); await api.add({ params?, body? }, ctx) -> Result<Output, ApiError>; never throws
- output describes the whole runtime body (see k.server); read r.value.results['kitchen.recipes'].value
- ApiError: api.status { status, body } (body decoded by errors[status], else null), api.network, api.timeout, api.decode, api.input
- pass a 422 on to the Form: if (!r.ok) return err(r.error.data.body?.error ?? r.error)
- ctx.net.fetch in app code is E1651; E1652 :param without params field; E1653 body on GET

k.forms
- import { form } from '@keel/forms'; const f = form(RecipeDraft, { initial?, id: 'recipes.draft' }) in a component; f.field('title') f.values() f.errors() f.pending() f.reset()
- field id is `<formId>:<path>` (recipes.draft:title), its error element `<formId>:<path>:error`
- <Form method="POST" action={routes.href('recipes.new')} form={f} error={(e) => <Text>{e.message}</Text>}><Input field={f.field('title')} label="Title" /><Button id="recipes.save" type="submit">Save</Button></Form>
- number fields coerce from input text; invalid submit sends nothing, sets every error, focuses the first invalid field
- action err keel.fields { [path]: message } sets exactly those errors; other err renders the error slot
- E1901 input in a Form without field; E1902 unknown path
