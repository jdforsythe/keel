k.schema

- s.string({ min, max }) s.number({ min, max }) s.int({ min, max }) s.boolean() s.literal(v) s.enum([...]) s.id('Brand') s.object({...}) s.array(T) s.union('tag', variants) s.record(T) s.json()

- type T = s.infer<typeof T>; T.parse(x): Result<T, SchemaError> (parses JSON from T.encode too; there is no decode); T.decodeStrings(FormData | URLSearchParams); gen(T) from '@keel/schema/gen'
- schemas live only in *.schema.ts, one export per file
- s.enum(values, { pathDefault }) names the value a leading path param leaves out of the URL (k.prefix); s.format is stdlib-only (E1106)

k.errors
- Result<T,E> = { ok: true, value } | { ok: false, error }; ok(v) / err(e); narrow on r.ok
- KeelError { code, message, data }; kernel codes keel.notFound keel.denied keel.fields keel.conflict keel.unexpected schema.invalid
- no throw (E1451), no try/catch or .catch() (E1452, use attempt), no discarded Result (E1453)

k.reactive
- signal(v), computed(fn), effect(fn, { writes: [] }), resource(fetcher); resource consumed only via Match (E1204); primitives outside a scope E1203
- resource(fetcher): a Result made by ok/err unwraps (ok(v) -> ready v, err(e) -> error e; a plain { ok, error } object stays ready), so resource(() => client.call(input, ctx)) needs no throw; a throw or rejection is also error

k.router
- API entry (no component): an entry of the contract with method, path and output, bound with loader (GET) or action (write) and an optional guard; the server answers it with JSON whatever accept says (GET with a loader: { id, results }; a write: the action Result as JSON (its output), never 303; a guard denial: 403 keel.denied); href, Link and navigate take page ids only; a component or errorElement on it is E1510; an API query may require keys (a failure is 422 keel.fields, nothing runs)
- API action: output is the entry's; the ok value is parsed before any store saves (fail: E1554, nothing saved); answered 200 { ok: true, value } with Cache-Control: no-store; a write with nothing to say: output: s.object({}) and ok({}); a page's action declares input and keeps ok(href) / ok(null); output holds no s.secret (E1113: send reveal(secret) in an s.string field, reveal only in *.server.ts)
- bearer: an API route's guard, loader and action get bearer: Secret<string> | undefined beside caller, from `Authorization: Bearer <token>` (scheme in any case, 1 to 4096 characters of A-Za-z0-9-._~+/ and trailing =); no header, another scheme, an empty or longer token or two headers is undefined (no error); a page's guard and loader get undefined, a page's action has none; independent of caller; a response to a request carrying authorization is no-store
- guard({}, fn) (no redirect) guards API routes only; on a page or layout it is a type error and manifest() throws E1508
- import { manifest, routeTable, guard, loader, action, Form, type Href } from '@keel/router'
- recipes.contract.ts: export const recipes = contract('recipes', { 'recipes.shell': { layout: true }, 'recipes.show': { path: '/:locale/recipes/:recipeId', params: RecipeParams } }); routes.ts: export const routes = manifest(recipes, { 'recipes.shell': { component: BoxShell, loader: loadShell }, 'recipes.show': { loader: loadRecipe, component: RecipePage, layout: 'recipes.shell', errorElement: RecipeError, guard: cook, title: (p: Infer<typeof RecipePageProps>) => formatMessage(p.data.text.showTitle, { title: p.data.recipe.title }, p.params.locale), POST: favoriteRecipe } }); the page's actions sit in its entry by verb; an action returning ok(recipes.href(...)) imports the contract, never routes.ts; a page's layout names a layout id of its contract or of another module's
- entry without path = layout, renders {props.children?.()}; a layout's loader and component get the matched route's params (a layout declares none: parse them); a static segment beats :param
- component receives { params, search, data } (data = loader ok value); errorElement receives { error: KeelError }
- Link to, navigate, Form action take Href only (E1501), from <contract>.href
- guards: export const cook = guard({ redirect: 'recipes.index' }, async ({ url }, ctx) => ok(null) | err({ code: 'keel.denied', message, data: null })); file *.guard.ts; the route holds the value (guard: cook); the redirect carries the matched route's same-name params (locale)
- route() { id, params, search, pending }; navigate(href, { replace? })
- <Form method="POST" action={recipes.href(...)} form? error?>: ok(href) navigates, ok(null) revalidates the chain's loaders
- client deployable: the router runs guards, loaders and actions in the browser; it refuses `stores`
- E1509 a route colliding with a prefix param (k.prefix); E1502 duplicate path, E1503 :param without params field, E1504 required search field, E1505 undeclared verb, E1506 unknown layout
