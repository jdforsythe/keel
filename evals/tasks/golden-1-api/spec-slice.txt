k.schema
- import { s, ok, err, attempt, type Result } from '@keel/schema'
- s.string({ min, max }) s.number() s.int() s.boolean() s.literal() s.enum([...]) s.id('Brand') s.object({...}) s.array(T) s.union (discriminated) s.record
- .optional() = key may be absent; .nullable() = value may be null; distinct (E1102)
- type T = s.infer<typeof T>; T.parse(x): Result<T, SchemaError>; T.encode/decode; T.gen() fast-check arbitrary
- schemas live only in *.schema.ts (E1104)

k.errors
- Result<T,E> = { ok: true, value } | { ok: false, error }; build with ok(v) / err(e); narrow on r.ok
- KeelError { code, message, data }; kernel codes keel.notFound keel.denied keel.fields keel.unexpected schema.invalid
- s.error(code, dataSchema) in *.schema.ts; .make(data, message?); app codes prefixed by module id
- no throw (E1451), no try/catch (E1452, use attempt), no discarded Result (E1453)

k.reactive
- signal(v), computed(fn), effect(fn, { writes: [] }), resource(fetcher)
- resource state: { state: 'loading' } | { state: 'error', error } | { state: 'ready', value }; consume only via Match (E1204)

k.store
- import { store, transaction, tx, invariant } from '@keel/store'
- export const board = store(Board, { lists: [], todos: [] }, { id: 'todos.board' })
- export const addTodo = transaction(board, 'todos.addTodo', s.object({...}), (state, payload) => nextState)  // pure (E1302)
- invariant(board, (state) => boolean)  // declared once beside the store; violation: err store.invariant, rollback
- reads board.get('todos'), board.select(fn) (computeds); writes only tx(addTodo, payload)
- board.log() entries { name, payload, at, id }; board.undo(); board.snapshot(); board.restore(snap)
- component declares uses (k.component); calling an undeclared tx from a component is E1301; loaders and actions are unrestricted

k.ctx
- ctx.clock.now() ctx.random.uuid()/float() ctx.random.id(brand) (branded id) ctx.net.fetch(req) ctx.storage.get/set
- createCtx({ mode: 'sim', seed }) -> SimCtx with net.route(pattern, (req) => Response), clock.advance(ms)
- Date.now, new Date(), Math.random, crypto.randomUUID, bare fetch, localStorage in app code: E1601
- resources fetch with `new Request(new URL('/api/x', location.href))` (relative URLs throw)
- ctx.net.fetch in app code is E1651: declare an endpoint (k.services) and call the client with ctx

k.component
- one default export per file, filename = name; export const Props = s.object(...)
- (props: Props, slots?, ctx?: Ctx) => JSX; ctx comes from the mount/island root or harness render; the only way a component reaches an effect; resource fetchers close over it
- a file may also export `export const uses = [toggleTodo]`; the compiler calls uses(...) in the component scope
- props are getters, never destructure (E1401)
- <If when>, <For each key="id">, <Match on={union}><Case tag="...">; {a && <b/>} is E1403
- ids: explicit id="todos.add" or derived <file>.<index>; duplicates E1404

k.runtime
- import { If, For, Match, Case, Boundary } from '@keel/runtime-dom'; mount is generated entry only
- no document/window/DOM APIs in app code (E1252)

k.router
- manifest({ 'todos.shell': { component, layout? }, 'todos.list': { path: '/lists/:listId', params: s.object({ listId: s.id('TodoList') }), search: s.object({ filter: s.enum([...]).optional() }), loader, actions: { POST: createTodo }, component, layout: 'todos.shell', guard: 'editable', errorElement } })
- entry without path = layout; its component renders a children slot
- component receives { params, search, data }; errorElement receives { error: KeelError }
- href(id, params?, search?) -> Href; Link to, navigate, URL attrs take Href only (E1501)
- guard(name, { redirect: routeId }, async ({ url }, ctx) => ok(null) | err(keel.denied)); file *.guard.ts
- route() computed { id, params, search, pending }; navigate(href, { replace? })
- <Form method action params? form? loading? error?> from '@keel/router'; ok(href) navigates; ok(null) revalidates
- client-only app: router runs guards, loaders, actions in the browser
- rules E1501-E1506 (Href, duplicate path, params/path mismatch, required search field, bad verb, unknown guard/layout)

k.server
- loader(OutputSchema, async ({ params, search }, ctx) => Result<T, KeelError>) in *.server.ts (E1551)
- action(InputSchema, async (input, { params }, ctx) => Result<Href | null, KeelError>) in *.server.ts
- topology.ts: topology({ web: { modules: ['todos'], adapter: 'client' }, api: { modules: ['api'], adapter: 'node' } }); a module is in one deployable (E1552)
- server entry: createApp({ topology, routes, ctx: createCtx({ mode: 'real' }), deployable: 'api', expose: [board], log }) -> { fetch }; validates only the served deployable; expose lists process-shared stores
- POST/PUT/PATCH/DELETE: body decoded with the action's input schema from FormData, or from JSON when content-type is application/json (a k.services client); fail: keel.fields 422, action not called
- runtime request (header accept: application/json): GET and POST return JSON { id: routeId, results: { [routeId]: Result } } where Result is { ok: true, value } | { ok: false, error: { code, message, data } }; a loader's value is its encoded output, an action's is null or an href
- status: keel.notFound 404, keel.denied 403, keel.fields 422, other err 400
- one route per path; actions by verb (E1502 duplicate path); a route may be action-only (component still required; a plain .ts component avoids JSX when run by `node server.ts`)
- tests: createApp({...}).fetch(new Request('http://x/api/lists', { headers: { accept: 'application/json' } })); in tests serve the api with the sim ctx and route sim ctx.net '/api/*' to app.fetch so client modules get real bodies

k.services
- import { endpoints, service } from '@keel/services' (output and body schemas are *.schema.ts, E1104)
- const todos = endpoints({ lists: { method: 'GET', path: '/api/lists', output: BoardReply }, addTodo: { method: 'POST', path: '/api/lists/:listId/todos', params: s.object({ listId: s.id('TodoList') }), body: TodoDraft, output: ActionReply, errors: { 422: FieldsReply } } })
- const api = service({ base: location.origin, schema: todos }); build it inside a function (location is absent when the compiler evaluates manifests in Node)
- r = await api.addTodo({ params, body }, ctx) -> Result<Output, ApiError>; the client never throws; requests go through ctx.net.fetch
- output must describe the whole runtime body: s.object({ id, results: s.object({ 'api.lists': s.object({ ok: s.literal(true), value: BoardView }) }) }); read r.value.results['api.lists'].value
- ApiError codes api.timeout api.network api.status { status, body (decoded by errors[status], else null) } api.decode api.input
- a declared 422 body (FieldsReply, a keel.fields error body) lets an action pass field errors on: return err(keel.fields data)
- E1652 :param without a params field; E1653 body on GET
