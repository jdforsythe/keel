k.schema
- import { s, ok, err, attempt, type Result } from '@keel/schema'
- s.string({ min, max }) s.number({ min, max }) s.int({ min, max }) s.boolean() s.literal(v) s.enum([...]) s.id('Brand') s.object({...}) s.array(T) s.union('tag', variants) s.record(T) s.json()
- .optional() = key may be absent; .nullable() = value may be null; distinct
- type T = s.infer<typeof T>; T.parse(x): Result<T, SchemaError> (parses JSON from T.encode too; there is no decode); T.decodeStrings(FormData | URLSearchParams); gen(T) from '@keel/schema/gen'
- schemas live only in *.schema.ts, one export per file

k.errors
- Result<T,E> = { ok: true, value } | { ok: false, error }; ok(v) / err(e); narrow on r.ok
- KeelError { code, message, data }; kernel codes keel.notFound keel.denied keel.fields keel.conflict keel.unexpected schema.invalid
- no throw (E1451), no try/catch or .catch() (E1452, use attempt), no discarded Result (E1453)

k.reactive
- signal(v), computed(fn), effect(fn, { writes: [] }), resource(fetcher); resource consumed only via Match (E1204); primitives outside a scope E1203
- resource(fetcher): a Result made by ok/err unwraps (ok(v) -> ready v, err(e) -> error e; a plain { ok, error } object stays ready), so resource(() => client.call(input, ctx)) needs no throw; a throw or rejection is also error

k.store
- import { store, transaction, tx, invariant, type Store } from '@keel/store'
- store(Schema, initial, { id: 'todos.board' }); transaction(store, 'todos.addTodo', PayloadSchema, (state, payload) => next) is pure (E1302: no ctx, no globals)
- invariant(store, (state) => boolean), declared once beside the store; a violating tx returns err store.invariant and rolls back
- reads store.get(key), store.select(fn); writes only tx(t, payload, { meta }?) -> Result; store.log(), undo(), undoWhere(pred), snapshot(), restore(snap)
- a component that calls tx exports uses = [t] (E1301 otherwise); loaders and actions are unrestricted

k.router
- API route (no component): { 'api.lists': { api: true, path: '/api/lists', loader: loadBoard } } plus routes.actions({ 'api.lists': { POST: postList } }); keeps params, search, loader, guard; refuses component, errorElement, title, layout (E1510); needs a loader or an action; the server answers it with JSON whatever accept says (GET with a loader: { id, results }; GET without one: 405 with allow; a write: the action Result as JSON, never 303; a guard denial: 403 keel.denied); routes.href, Link and navigate take page ids only
- guard({}, fn) (no redirect) guards API routes only; on a page or layout it is a type error and manifest() throws E1508
- import { manifest, guard, loader, action, Form, type Href } from '@keel/router'
- routes.ts: export const routes = manifest({ 'todos.shell': { component: AppShell }, 'todos.edit': { path: '/lists/:listId/todos/:todoId/edit', params: TodoParams, loader: loadTodo, component: EditTodoPage, layout: 'todos.shell', errorElement: ListError, guard: editable } }); then routes.actions({ 'todos.edit': { POST: updateTodo } }) (a statement; actions are never in an entry: E1505); an action returning ok(routes.href(...)) imports routes.ts, which imports it: import routes.ts (never the *.server.ts) first in tests
- entry without path = layout, renders {props.children?.()}; a static segment beats :param
- component receives { params, search, data } (data = loader ok value); errorElement receives { error: KeelError }
- links: routes.href(id, params?, search?) -> Href, typed by the manifest; Link to, navigate, Form action take Href only (E1501)
- guards: export const editable = guard({ redirect: 'todos.index' }, async ({ url }, ctx) => ok(null) | err({ code: 'keel.denied', message, data: null })); file *.guard.ts; the route holds the value (guard: editable)
- route() { id, params, search, pending }; navigate(href, { replace? })
- <Form method="POST" action={routes.href(...)} form? error?>: ok(href) navigates, ok(null) revalidates the chain's loaders
- client deployable: the router runs guards, loaders and actions in the browser; it refuses `stores`
- E1502 duplicate path, E1503 :param without params field, E1504 required search field, E1505 undeclared verb, E1506 unknown layout, E1507 params/search typed by hand

k.server
- loader({ output, params?, search?, stores? }, fn): fn({ params, search, url, caller, stores }, ctx) -> Promise<Result<T, KeelError>>
- action({ input, params?, stores? }, fn): fn(input, { params, url, caller, stores }, ctx) -> Result<Href | null, KeelError>; return a link as `ok(routes.href(...))`
- both only in *.server.ts (E1551); params/search are the route's own schemas; never annotate fn; url is absolute; server code never reads location
- stores: a factory (ctx?) => S of stores (explicit ids) and transactions bound to them; per request it runs once, its stores restore from ctx.storage `keel.store.<id>`; an action's ok saves them (409 keel.conflict if another request saved first); err saves nothing
- topology.ts: import { topology } from '@keel/server'; export default topology({ web: { modules: ['todos'], adapter: 'client' }, api: { modules: ['api'], adapter: 'node' } }); a module is in one deployable (E1552)
- createApp({ topology, routes, ctx, deployable: 'api', runners?, peers?, artifacts? }) from '@keel/server' -> Promise<{ fetch(req), close() }> (tests; production runs the generated entry)
- live loader: loader({ output }, async function* ({ signal }, ctx) { yield ok(v) }); document/JSON GET takes the first yield; accept: text/event-stream gets each yield as a `data:` line (its Result JSON)
- writes pass the same-site check: send accept: application/json with x-keel: 1 (a services client does)
- JSON body (content-type application/json) decodes with the action input schema, an empty body as {}; fail: 422 keel.fields naming each bad or missing field, action not called
- runtime JSON (accept: application/json): GET -> { id: routeId, results: { [routeId]: { ok: true, value } } }; action -> { ok: true, value: null | href } or { ok: false, error: { code, message, data } }
- status: keel.notFound 404, keel.denied 403, keel.fields 422, keel.conflict 409, other err 400
- a route may be action-only (an API route: `api: true`, no component; its loader or action is all it has)

k.services
- import { endpoints, service } from '@keel/services'; endpoints in a *.service.ts file, body/output schemas in *.schema.ts
- export const todos = endpoints({ lists: { method: 'GET', path: '/api/lists', output: BoardReply }, editTodo: { method: 'POST', path: '/api/todos/:todoId', params: TodoIdParams, body: TodoDraft, output: ActionReply, errors: { 422: FieldsReply } } })
- service({ module: 'api', schema }): the topology resolves the origin (a browser: the peer's or the page's); the endpoints must agree with the module's public.routes (E1152, E1157, E1561: errors must accept any error answer of the route); await api.add({ params?, body? }, ctx) -> Result<Output, ApiError>; never throws
- output describes the whole runtime body (see k.server); read r.value.results['api.lists'].value
- ApiError: api.status { status, body } (body decoded by errors[status], else null), api.network, api.timeout, api.decode, api.input
- pass a 422 on to the Form: if (!r.ok) return err(r.error.data.body?.error ?? r.error)
- in an unbound sim ctx a service({ module: 'api' }) call goes to http://api.keel.invalid plus the path; route that host with ctx.net.route
- ctx.net.fetch in app code is E1651; E1652 :param without params field; E1653 body on GET
- service({ module: 'api', schema }) calls app module api's routes (api in deps, route in its public.routes): in process, a peer, a browser's document origin; on a ctx no createApp bound, http://api.keel.invalid

k.topology
- each module (app or stdlib) in one deployable; a split edits topology.ts alone
- keel build writes dist/<name>/server.mjs per node deployable (no server.ts): env PORT (8080), KEEL_SECRET (32+, one for the app), KEEL_ORIGIN, KEEL_PEER_<NAME>; E1560 names a bad key; SIGTERM awaits close() and exits
- modules/<id>/runners.server.ts: export const runners = [jobs, schedules]; createApp({ runners: { digest: runners } }) runs them after startup; close() aborts them
- a client deployable may carry host: 'api' (k.hosting): topology({ web: { modules: ['todos'], adapter: 'client', host: 'api' }, api: { ... adapter: 'node' } })
- peers: a request for a path a peer serves (routes.json in artifacts) is forwarded; deploy/<name>/Dockerfile and deploy/compose.yaml are generated (E1005)

k.hosting
- k.hosting: `host: '<node deployable>'` on a `client` deployable names the `node` deployable that serves it; keel build writes dist/<client>/ (index.html, assets/, keel-mark.svg) and copies it into dist/<host>/; the host answers a GET document request matching none of its routes with index.html (200, no-cache), an unmatched runtime or event-stream request or a path under /assets/ stays 404; KEEL_PEER_<NAME> at build adds a keel-peer meta tag, so service({ module }) in a browser calls that origin with credentials, else the document's origin; KEEL_ALLOW_ORIGINS (createApp({ allow })) lets listed origins call API routes; E1565 bad peer value, E1566 bad host
