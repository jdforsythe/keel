- live loader: loader({ output }, async function* ({ signal }, ctx) { yield ok(v) }); document/JSON GET takes the first yield; accept: text/event-stream gets each yield as a `data:` line (its Result JSON)
- writes pass the same-site check: send accept: application/json with x-keel: 1 (a services client does)
- JSON body (content-type application/json) decodes with the action input schema, an empty body as {}; fail: 422 keel.fields naming each bad or missing field, action not called
- runtime JSON (accept: application/json): GET -> { id: routeId, results: { [routeId]: { ok: true, value } } }; page action -> { ok: true, value: null | href }; API action -> { ok: true, value: <output> } or { ok: false, error: { code, message, data } }
