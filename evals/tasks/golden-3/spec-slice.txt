k.schema
- import { s, ok, err, attempt, type Result } from '@keel/schema'
- s.string({ min, max }) s.number({ min, max }) s.int({ min, max }) s.boolean() s.literal(v) s.enum([...]) s.id('Brand') s.object({...}) s.array(T) s.union('tag', variants) s.record(T) s.json()
- .optional() = key may be absent; .nullable() = value may be null; distinct
- type T = s.infer<typeof T>; T.parse(x): Result<T, SchemaError> (parses JSON from T.encode too; there is no decode); T.decodeStrings(FormData | URLSearchParams); gen(T) from '@keel/schema/gen'
- schemas live only in *.schema.ts, one export per file

k.errors
- Result<T,E> = { ok: true, value } | { ok: false, error }; ok(v) / err(e); narrow on r.ok
- KeelError { code, message, data }; kernel codes keel.notFound keel.denied keel.fields keel.conflict keel.unexpected schema.invalid
- no throw (E1451), no try/catch or .catch() (E1452, use attempt), no discarded Result (E1453)

k.reactive
- signal(v), computed(fn), effect(fn, { writes: [] }), resource(fetcher); resource consumed only via Match (E1204); primitives outside a scope E1203
- resource(fetcher): a Result made by ok/err unwraps (ok(v) -> ready v, err(e) -> error e; a plain { ok, error } object stays ready), so resource(() => client.call(input, ctx)) needs no throw; a throw or rejection is also error

k.store
- import { store, transaction, tx, invariant, type Store } from '@keel/store'
- store(Schema, initial, { id: 'todos.board' }); transaction(store, 'todos.addTodo', PayloadSchema, (state, payload) => next) is pure (E1302: no ctx, no globals)
- invariant(store, (state) => boolean), declared once beside the store; a violating tx returns err store.invariant and rolls back
- reads store.get(key), store.select(fn); writes only tx(t, payload, { meta }?) -> Result; store.log(), undo(), undoWhere(pred), snapshot(), restore(snap)
- a component that calls tx exports uses = [t] (E1301 otherwise); loaders and actions are unrestricted

k.ctx

k.component
- one default export per file, filename = name: (props) => JSX, or (props, ctx: Ctx) => JSX when it reaches an effect (ctx never optional, defaulted or followed by a parameter: E1407; every caller passes one); export const Props = s.object(...); a plain .ts component (PascalCase file, no JSX, default export a function whose first parameter is typed from Props: (props: Infer<typeof Props>)) may export Props and uses too
- props are getters, never destructure (E1401); <If when>, <For each key="id">, <Match on={union}><Case tag>; {a && <b/>} is E1403
- explicit ids on everything a test touches (id="todos.addTodo", id={`todos.row.${t.id}`}); duplicates E1404

k.runtime
- import { If, For, Match, Case } from '@keel/runtime-dom'; mount(Component, el, { ctx }) is the generated entry only; no document/window in app code (E1252)

k.router
- API entry (no component): an entry of the contract with method, path and output, bound with loader (GET) or action (write) and an optional guard; the server answers it with JSON whatever accept says; href, Link and navigate take page ids only; a component on it is E1510
- guard({}, fn) (no redirect) guards API routes only; on a page or layout it is a type error and manifest() throws E1508
- import { manifest, routeTable, guard, loader, action, Form, type Href } from '@keel/router'
- shifts.contract.ts: import { contract } from '@keel/router/contract'; export const shifts = contract('shifts', { 'shifts.shell': { layout: true }, 'shifts.show': { path: '/shifts/:shiftId', params: ShiftParams } }); one contract per module, its export named for the module (E1513); imports *.schema.ts files and packages only (E1514); a page is { path, params?, search? }, a layout { layout: true }; routes.ts: export const routes = manifest(shifts, { 'shifts.shell': { component: AppShell }, 'shifts.show': { loader: loadShift, component: ShiftPage, layout: 'shifts.shell', errorElement: ShiftError, guard: organizer, POST: signUp } }): every entry bound and nothing else (E1515), a page's actions sit in its entry by verb, its layout is a layout id of its contract or another module's; an action returning ok(shifts.href(...)) imports the contract, never routes.ts
- entry without path = layout, renders {props.children?.()}; a static segment beats :param
- component receives { params, search, data } (data = loader ok value); errorElement receives { error: KeelError }
- links: shifts.href(id, params?, search?) -> Href, typed by the contract (pages only); Link to, navigate, Form action take Href only (E1501)
- guards: export const editable = guard({ redirect: 'todos.index' }, async ({ url }, ctx) => ok(null) | err({ code: 'keel.denied', message, data: null })); file *.guard.ts; the route holds the value (guard: editable)
- route() { id, params, search, pending }; navigate(href, { replace? })
- <Form method="POST" action={shifts.href(...)} form? error?>: ok(href) navigates, ok(null) revalidates the chain's loaders
- client deployable: the router runs guards, loaders and actions in the browser; it refuses `stores`
- E1502 duplicate path, E1503 :param without params field, E1504 required search field, E1505 undeclared verb, E1506 unknown layout

k.server
- loader(contract, id, { output?, stores? }, fn): fn({ params, search, url, caller, bearer, stores }, ctx) -> Promise<Result<T, KeelError>>; params and search come from the entry
- page action(contract, id, { input, stores? }, fn): fn(input, { params, url, caller, stores }, ctx) -> Result<Href | null, KeelError>; return a link as `ok(shifts.href(...))`; an API entry's action takes { stores? } and its body is the entry's `body`
- both only in *.server.ts (E1551); a handler bound under another id is E1515; never annotate fn; url is absolute; server code never reads location
- stores: a factory (ctx?) => S of stores (explicit ids) and transactions bound to them; per request it runs once, its stores restore from ctx.storage `keel.store.<id>`; an action's ok saves them (409 keel.conflict if another request saved first); err saves nothing
- topology.ts: import { topology } from '@keel/server'; export default topology({ web: { modules: ['todos'], adapter: 'client' }, api: { modules: ['api'], adapter: 'node' } }); a module is in one deployable (E1552)
- createApp({ topology, routes, ctx, deployable: 'api', runners?, peers?, artifacts? }) from '@keel/server' -> Promise<{ fetch(req), close() }> (tests; production runs the generated entry)
- live loader: loader({ output }, async function* ({ signal }, ctx) { yield ok(v) }); document/JSON GET takes the first yield; accept: text/event-stream gets each yield as a `data:` line (its Result JSON)
- writes pass the same-site check: send accept: application/json with x-keel: 1 (a services client does)
- JSON body (content-type application/json) decodes with the action input schema, an empty body as {}; fail: 422 keel.fields naming each bad or missing field, action not called
- runtime JSON (accept: application/json): GET -> { id: routeId, results: { [routeId]: { ok: true, value } } }; page action -> { ok: true, value: null | href }; API action -> { ok: true, value: <output> } or { ok: false, error: { code, message, data } }
- status: keel.notFound 404, keel.denied 403, keel.fields 422, keel.conflict 409, other err 400
- an API entry has a loader or an action and no component

k.forms

k.a11y
- target WCAG 2.2 A and AA; required props are types (E1802): Heading level, Image alt or decorative, label on Input/TextArea/Select/Checkbox and on Box as nav or aside, Link text, Button text children
- autocomplete: Autofill on Input, TextArea, Select, written as the attribute: name, email, tel, street-address, bday, ... or off (the data is not the user's own, or not a purpose)
- contrast: 4.5:1, 3:1 at fontSize >= 24px or >= 18.66px at weight 700; per scheme and breakpoint; E1804 statically (bg on the element or an ancestor in the same component) and at render (nearest painted ancestor, else #FFFFFF)
- no tabindex, order, position, z-index or outline exist: focus order is document order; direction row-reverse/column-reverse over two or more focusable elements is E1820
- harness: t.focusOrder() -> ids of focusable elements in sequential order (no disabled or hidden ones)
- render checks after the first render, every fire and settle(): a11y.json roles (E1702), axe-core wcag2a/2aa/21a/21aa/22aa rules (E1703; renderRoute also runs document-title, html-has-lang, landmark-one-main, region, bypass), render contrast (E1804), a data-k-pii control without autocomplete (E1821)
- renderRoute renders the document: <html lang>, <title>, the chain as the main landmark unless it renders one
- claims: keel test writes reports/a11y.json; keel ledger emits a11y:<routeId>#<criterion> at example when a passing renderRoute test rendered the route and every rule mapped to the criterion ran with no violation; else none. A claim is about the checks, not the criterion

k.security
- every createApp response: X-Content-Type-Options nosniff, Referrer-Policy same-origin, Cross-Origin-Opener-Policy same-origin, Cross-Origin-Resource-Policy same-origin, X-Frame-Options DENY, Permissions-Policy camera=(), microphone=(), payment=(), usb=(); on https also Strict-Transport-Security
- every document: Content-Security-Policy (Report-Only in dev) default-src 'none'; script-src 'nonce-<n>' 'strict-dynamic'; style-src 'self'; img-src 'self'; font-src 'self'; connect-src 'self'; manifest-src 'self'; form-action 'self'; frame-ancestors 'none'; base-uri 'none'; object-src 'none'; require-trusted-types-for 'script'; trusted-types keel; report-uri /__keel/csp; report-to keel-csp
- the nonce is new per response; the policy has no option: no inline script or style, no style attribute, no on* attribute, no other origin
- POST /__keel/csp logs one { kind: 'csp', directive, blocked, route } record per report
- E1570 a literal absolute http(s) URL in src, action, Image src, ... (fix: none); E1571 a literal absolute http(s) URL given to ctx.net.fetch or service({ base }) in client-reachable code

k.privacy
- schema.pii(class) marks a node and everything under it as personal data, in a *.schema.ts file; PiiClass: name, contact, location, identifier, financial, special, network, content
- the mark keeps the type and parse/encode/decodeStrings/gen; doc() appends pii(<class>); JSON Schema x-keel-pii
- import { piiPaths, piiValues } from '@keel/schema': piiPaths(schema) -> { path, class }[]; piiValues(schema, value) -> the non-empty strings and numbers under marked paths
- sinks: sessions replace marked values with generated ones; a control bound to a marked path carries data-k-pii and its input reaches observers as x repeated; a diag log record holds [pii] for each marked value of the request's input, loader and action outputs and store states, and [secret] for each Secret input; the evidence bundle holds no app value
- E1111 a .pii() node in a route's params or search schema (fix: none); E1105 reveal outside *.server.ts; E1113 an s.secret in a loader or action output

k.evidence
