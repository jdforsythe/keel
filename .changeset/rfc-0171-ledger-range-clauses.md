`keel ledger` holds a clause with `each` and a code range (`E2001-E2005`, `E2401 to E2406`) at a rung only while every code of the range is named, outside the quote, in the header of a citing file with a non-skipped test; a range in a header names its two ends. A clause that loses a code is `none`, which `keel ledger --diff` reports as E1706 and E1707. An escaped quote (`\"`) in a `// Spec:` header reads as a quote.
