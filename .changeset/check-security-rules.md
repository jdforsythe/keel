`keel check` security rules follow every way code reaches a file. Reach (E1004, E1571, E1107) and k.origins' importers follow a specifier as k.bundle Aliases resolves it, a template `import()` with a relative head included (`declaredFor` and `clientReach` take a `resolve`). E1015: a relative specifier in non-test project code that resolves outside the project. E1107 judges every `store` call in reach under any spelling, and reports an unreadable state schema, `stores()` and `store` used as a value. The schema read follows a literal binding only while it is held. E1108 consults the format registry only for a `@keel/std-*` package in `deps`. E1571's message names `connect`. Every schema `@keel/schema` makes, its node and `s` are frozen. A write target with more than one hard link is refused (E1357, E1585).
