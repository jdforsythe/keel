std.sessions ingest by caller and a fingerprint recomputable from the session (backlogs 0225, 0226, RFC 0072). `sessions.ingest` files each session with the request's `caller` and its encoded size. Past 5 sessions in a fingerprint, the caller holding the most there loses its oldest. One caller holds at most 1 MiB in 16 fingerprints, and its own oldest sessions go past that. Past 64 fingerprints or 4 MiB, the caller with the largest share loses its oldest session first, so one caller's flood never evicts another caller's sessions. Archive size is tracked per session, so a write never re-encodes the archive. `sessions.list` returns the sessions without callers. The `error` session event carries `route`, the route id it fired under. The fingerprint hashes the first error event's code, recorded `data.at` and route, so the recorder, `replay`, `minimize` and the ingest compute the same value from the session alone. The ingest always recomputes `fingerprint` and `error` and never keeps a posted value. `replay` seeds every live store, starting one the base `state` lacks at its `initial`, so `minimize` is deterministic whatever the live stores held.
