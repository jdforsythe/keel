`keel docs` lists the areas of the docs and the skills; `keel docs <area>` lists an area's sections with what each holds; `keel docs --for` takes a code, a code block (`E155x`), an API name or a glossary term. `@keel/cli` packs `docs/map.json` by area and `docs/glossary.json`. The `AGENTS.md` block names the area form.
