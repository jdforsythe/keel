`KEEL_SECRET` is checked as 32 or more UTF-8 bytes. The E1562 fix is offered only when the route source spells the field out. A path with a trailing slash collides with the same path without it. In dev, the next apps load after the old ones have closed. The generated CI path filter covers each deployable's transitive app-module deps. A due job runs however many later jobs wait.
