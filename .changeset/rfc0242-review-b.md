`defect` has one form, `defect(message, { code, data, cause })`: the code is the detail's `code`, and E1455 reads it there. `supervise` refuses a `failed` that is no `KeelError` with the defect E1458 before `fn` runs, takes a returned value whose inspection throws as a throw of `fn`, and sets no time of its own. A channel stream's re-read of its stores and `member` after a save is a denial when not settled within 5,000 ms on `ctx.clock`. In `races`, a transaction function that throws an `Error` other than a `TypeError` or `RangeError` makes its entry `unchecked` `threw`.
