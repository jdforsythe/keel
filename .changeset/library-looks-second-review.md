k.values is a grammar: math functions, `env(safe-area-inset-*)`, every current unit, quoted families with commas and `currentColor` in borders and shadows, and only values that take effect; no client bundle holds it. k.entries holds every library `exports` to one shape (E1815), and nothing of a library is evaluated or bundled while one stands; a library's tokens file is never evaluated. A disabled `button` or `switch` in a roving group stays focusable.
