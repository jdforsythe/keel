`keel evidence` writes an Ed25519-signed evidence bundle and `--verify` checks one (E1060-E1064); `@keel/cli/evidence` exports the bundle file schemas. `keel test` writes `reports/a11y.json`, `keel ledger` emits `a11y:<routeId>#<criterion>` claims, `keel build` writes `csp.txt` for `client` and `static` deployables, and JSON Schemas carry `x-keel-pii`.
