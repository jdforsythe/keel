A file under `unsafe/` is app code but for its lifted ranges (k.check, App code): the function given as the second argument of an `unsafe(reason, () => ...)` call. Inside a range E1252, E1451, E1452, E1601, E1603, E1651, E1757, E1758 and E1759 are not reported; every other code, the stdlib's E2406, E2601 and E2602 included, reads the range and the rest of the file. E1757 in an `unsafe/` file reads `outside an unsafe() call; use a guard or move it into the call`.
