The std.sessions GitHub Action. `packages/std-sessions/action/action.yml` is a composite action with inputs `url` and `token` (exported as `KEEL_SESSIONS_TOKEN`), its actions pinned by commit SHA, that installs in `working-directory` and runs the new bin `keel-session-action` (`dist/src/actionBin.js`). The new subpath `@keel/std-sessions/action` exports `runAction(io)`: it ingests failing sessions of the last 26 hours, replays each fingerprint's files newest first until one reproduces, then runs `minimize` and `to-test` and creates (at most 20 a run) or updates one `keel-session` issue titled `session <fingerprint>: <code> at <route>`, whose body holds the compact `session` record and the emitted test. A fingerprint that does not reproduce gets one marked comment on its open issue per streak. Log lines and titles are sanitized, and a route id or code outside `[A-Za-z0-9_.-]` is E2002. The bin takes `--format`, `--quiet` and `--limit`. Output adds record kind `session.issue`.
