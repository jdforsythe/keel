`keel check`, `keel build`, `keel test` and `keel dev` judge the tree, never the derived files on disk: each takes the derivation of the tree it runs over and rewrites each `.keel/` view and deploy file whose bytes differ (`ok check 217 files, 2 refreshed, 0 errors`; W1018 when one cannot be written). A run with `--frozen`, `CI` set or `KEEL_FROZEN=1` writes nothing and reports a differing view as E1005. `routes.json` and `surface.json` come from one evaluation, cached in `node_modules/.cache/keel/derived/` while every file it loaded or read through `node:fs`, every `process.env` name it read and every symbolic link on the path to a file it loaded or read, and every `node_modules/<name>` entry, resolves as before; the evaluation sees `process` by any name (`globalThis`, `global`, `createRequire`, `process.getBuiltinModule`), a file read by a descriptor it opened and a `.json` file required by a computed name, records every lookup of its resolver and of its own `require`, a path found absent too, so creating it re-evaluates, and denies by default: every host view (the global object, `process`, each Node built-in) has one allowlist, `HOST_VIEWS`, of members it observes (each read a probe: a stat's fields the code reads, stable facts of `process`, `os` and `navigator`, and always the working folder, Node's version and the default locale and time zone) or gives as they are, and refuses everything else with E1050, its message starting with what it refused and placed at the refused call's project file and line, or naming `<package>/<path>:<line>` for a call in a package: a fact that moves (`os.cpus()`, `process.pid`), a stat's `atime`, a call into a child process, worker or network built-in, a `.node` addon, a code file named at run time (a computed `import()` too), Node's own loader, `Function` and `eval` by any spelling; the evaluation's writes to the global object and `process.env` stay its own; each module's `import.meta` is its own, and the evaluation's `console` writes nowhere; `keel dev` refreshes on a change to any of those files, a lone contract edit included; `keel check --base <file>` never rewrites that file; the json summary's `counts` hold `refreshed`, `evaluated` and `cached`. `surface.json` is version 3 with no `sources`; `--base` reads versions 2 and 3. Only `surface.json` and the deploy files are committed; a scaffolded `.gitignore` lists the other views. `keel pack --frozen` replaces `keel pack --check`. W1005 is reserved and never reported.
