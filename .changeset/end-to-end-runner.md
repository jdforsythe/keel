The end-to-end runner's guarantees (k.e2e-run): Chromium with its sandbox on, checked by one launch before any file (E1734 naming the sysctls, the seccomp setting and `--no-sandbox` when it cannot start; `KEEL_E2E_SANDBOX=unavailable` the test seam), off only with `keel test --e2e --no-sandbox` or as root on Linux, each a W1734 on every run, and a new profile inside the run's one `keel-e2e-*` folder, which `keel test --e2e` points `TMPDIR` at, removes on every end (a `stopped:` line on SIGINT or SIGTERM) and sweeps when a SIGKILLed run left it; a key made per run and a certificate per `serve` for its mapped host names alone; every request of a page to an origin the run neither serves nor maps refused at the serve's proxy before it reaches any server, an `offsite` problem; a served process given `PATH`, `LANG`, `LC_ALL`, `TZ`, its own `HOME` and temporary folders, and `env`, nothing else of the shell; every server the run starts on `127.0.0.1`; a non-Keel error printed `uncaught: <code> <line>`, never under `fix:`. Pages: `problems(...expected)` takes what an entry matches and a bare call takes nothing; `log(store)` gives SHA-256 digests of the stored snapshot and each entry's payload; `resume({ grows })` records every element under each island root; `upload`, `download`, `hover`, `opened()` and the `dialog` problem; an unknown id is E1705 at once with 3 nearest ids, an id inside a frame E1705 too. A library's `serve({ page, props, wrap?, tokens? })` writes its host in `.keel/e2e-host-<random>/` per call, removed at dispose; `page` under `src/`, `wrap` and `tokens` under `test/` (E1736). `keel dev` listens on loopback alone, a Vite `server.host` past it is E1560, and `keel dev --host <address>` listens wider with W1569 while `/__keel/inspect` answers loopback connections only. A `node` deployable's `server.mjs` listens on `HOST` when it is set. A page or API entry may declare `local: true` (k.contract Local routes): the server answers it only over a loopback connection with a loopback `Host` and `Sec-Fetch-Site` `same-origin` or `none`, else 403 `keel.denied` before any handler runs; `routes.json` marks it, and `createApp`'s `fetch` takes the connection as its second argument.
