`#k-state` carries a request store only when an island level's server render created, looked up through `stores()` or read it; a page with no island ships `stores: {}`. The production entry and `keel dev` handle uncaught exceptions and unhandled rejections with one E1577 record; production then stops listening, drains requests in flight for at most 10 s, closes storage and exits 1, while dev keeps serving. A queued `submit` is prevented at capture and submitted natively once at replay unless a handler prevented it, and a click on a non-fragment link is not queued. E1107 reports a `store` in client-reachable code whose state holds a `.pii()` class the module manifest's new `clientPii` list does not name, with a fix adding it. E1256's message names the four refused operations.
