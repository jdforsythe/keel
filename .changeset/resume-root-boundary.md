Each island `resume` resumes gets the root Boundary `mount` gives its tree: a throw after the claim is reported to the ctx as `keel.unexpected` and the island is replaced by the root fallback (`<pre data-k-error>`), so it is never an uncaught page error and observers see it. A handler's throw carries `data.at` the id it was registered under, else its element's when it throws, under `mount` and `resume` alike. The compiler keeps a `@keel/runtime-dom` import whose intrinsic is called or passed as a value, so a plain `.ts` module calling `If(...)` or `Boundary(...)` works in the browser.
