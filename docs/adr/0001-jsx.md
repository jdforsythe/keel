# ADR-0001: JSX is the view syntax

**Status:** accepted
**Context.** View syntax must be in-distribution for agents; template dialects (Vue, Svelte, Astro) have thin training data and invisible rules.
**Decision.** JSX with explicit control-flow components (`If`, `For`, `Match`). No template language.
**Alternatives.** Svelte-style templates (thin data); Vue templates (mini-language); hyperscript (unreadable at scale).
**Consequences.** Compiler owns JSX to DOM ops; `{cond && …}` and missing keys are compile errors.
