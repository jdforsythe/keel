# ADR-0209: k.ui defaults: a base from the tokens, named looks, a `gap` that names its axis, a brand focus ring (RFC 0188)

**Status:** accepted (operator, 2026-11-22: all of RFC 0188, `gap` without `direction` as a check error). Supersedes ADR-0067's rejection of a brand base stylesheet.

**Context.** An app on `brandTokens` loads the brand's custom properties and fonts, but no rule uses them: `body`, controls, links and focus keep the platform's look until each use sets a dozen style props, and a set cannot be declared once (findings S-2, S-7, S-9, S-11). `gap` without `direction` spaces nothing (S-4), the no-script 422 summary is bare and names the schema path (S-8), and an unbroken string widens a phone page (S-10). ADR-0067 rejected a brand stylesheet the server writes as a second styling path.

**Decision.** `tokens.ts` gains `base` (style sets per element role, and a `focus` color) and `look` (named style sets). The one compiled stylesheet writes a `keel.base` cascade layer: `[hidden]` hidden, `body` `overflow-wrap: anywhere`, each base set on its role class, and a 2px `:focus-visible` outline in `base.focus`. Atomic rules stay unlayered, so a style prop wins. `look="<name>"` expands to the set's classes, the element's own props replacing the set's per prop. Controls take `styles` parts `field`, `label`, `error`. The 422 summary names fields by their label and carries `k-summary`. `gap` with no `direction` is E1809 in `keel check`. `brandTokens` ships the brand's `base` and the looks `control`, `primary`, `secondary`; `BRAND.md` gains a focus rule: a 2px Charcoal ring, 2px outside the element, at 15.75:1 or more on every brand surface (WCAG 2.2 2.4.7, 1.4.11, 2.4.13).

**Alternatives.** A server-written brand stylesheet (ADR-0067's rejected option); `gap` without `direction` stacking as a column at zero specificity; an Ochre ring; looks as exported objects in `*.look.ts`; spreads in style props; the platform focus ring kept.

**Consequences.** Every app on `brandTokens` renders on brand with no app code and overrides through its tokens; an app with its own tokens and no `base` is unchanged. k.ui, k.a11y and k.forms read `implemented` until k.ui 17 to 23, k.a11y 15 and k.forms 17 are covered. One new code, E1809.
