# Threat model (seed)

Assets: user data in stores and logs; secrets in server env; session files. Adversaries: web attackers (XSS, CSRF, injection), malicious dependencies, agents reaching for `unsafe`. Kernel commitments: escaped output by default; `s.secret` values (`Secret<T>`) serialize and log only as `"[secret]"`, never restore from JSON, and are read only by `reveal` in `*.server.ts` (k.schema Secrets, RFC 0026; E1105 check rule pending); `.server.ts` cannot reach the client; parameterized queries only (stdlib db); `unsafe.*` justified and counted; servers default to production mode; writes need same-site proof (`Sec-Fetch-Site`, `Origin`, or `x-keel`); the dev inspect endpoint answers only its own or listed origins on a loopback or listed host; `#k-state` carries no process-shared logs unless opted in (RFC 0022). Grows per package.
