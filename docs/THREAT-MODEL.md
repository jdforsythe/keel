# Threat model (seed)

Assets: user data in stores and logs; secrets in server env; session files. Adversaries: web attackers (XSS, CSRF, injection), malicious dependencies, agents reaching for `unsafe`. Kernel commitments: escaped output by default; `Secret<T>` cannot serialize or log; `.server.ts` cannot reach the client; parameterized queries only (stdlib db); `unsafe.*` justified and counted; servers default to production mode; writes need same-site proof (`Sec-Fetch-Site`, `Origin`, or `x-keel`); the dev inspect endpoint answers only its own or listed origins on a loopback or listed host; `#k-state` carries no process-shared logs unless opted in (RFC 0022). Grows per package.
